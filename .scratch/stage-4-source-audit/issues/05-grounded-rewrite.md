# 05：带引用的修改建议与核心路径验收

**What to build:** 核验结束后，用户看到原配文与一条建议配文，每处改动有当前有效证据或保留不确定性的理由；据此冻结参赛核心路径。

**Blocked by:** 04：补充关键信息并恢复调查

**Status:** ready-for-agent

- [ ] 建议只使用当前主张及已采用的证据；逐处关联原句、修改内容、理由和引用。可以用来源中的正确数字替换原文错误值，不能引入证据未覆盖的数值、月份、范围或更强的因果表述。
- [ ] 对未解决主张保留限定或建议删除，显示原因；无法生成有依据建议时明确说明，不能为完成输出而补造事实。
- [ ] 建议由用户选择采用，不自动替换原配文；更改上游输入或引用失效后撤回旧建议并保留历史标识。
- [ ] 页面贯通「上传图文 → 主张拆解 → 工具检索 → 推断检查 → 必要补证 → 修改建议」，可展开实际核验过程。
- [ ] 沿 API、页面和独立评测检查引用有效性、未解决项保留及新事实引入；模型语义正确性单列真实调用复核，不能只靠引用 ID 存在判定通过。
- [ ] 复跑增量后的完整固定题集与有无检索对照，保留失败和退化结果，达到规格中功能门槛；完整行为测试、浏览器测试及构建通过。
- [ ] 更新 01—05 的真实完成状态及证据索引，交付给阶段五材料任务。若 06 未验收，演示不声称具备反证或版本复查。
