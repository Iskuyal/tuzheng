# 03：拆解短配文并检查推断依据

**What to build:** 上传一张 CPI 图和短配文，得到最多三条独立主张的原文、依据和状态；即使数字正确，也能指出现有证据不能推出的结论。

**Blocked by:** 02：证据不足分支与检索增益评测

**Status:** ready-for-agent

- [ ] 区分直接陈述、可检查推断与不支持核验的观点，保留各自图文原文及出处；超过三条时明确提示缩小配文，不能静默漏掉主张。
- [ ] 首批限定 CPI 同比／环比、涨幅与价格水平，逐项显示来源支持、来源矛盾或推断依据不足。数字正确不能直接推出整句成立；缺依据不能自动判为假。
- [ ] 自制「同比涨幅下降 → 比上月便宜」案例在没有适用环比材料时指出推断缺口；有适用来源时按来源给出对应结果。
- [ ] 模型选择工具及引用与主张关联；按调查共享调用预算，达到上限时保留已核验项并明确剩余项未完成。
- [ ] 页面可逐条展开证据；更正或重查一条主张不把结果套到其他主张。沿用 API 与浏览器接缝验证行为，再单列真实模型拆解和推断结果。
- [ ] 固定评测增加正确推断、错误推断、证据不足与观点案例，保留 02 原题，按实测更新规格和路线图。
