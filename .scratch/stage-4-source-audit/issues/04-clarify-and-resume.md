# 04：补充关键信息并恢复调查

**What to build:** 模型提出一个会影响当前主张的关键问题，用户补充后恢复核验；现场改月份或范围能让旧结论立即失效并重新调查。

**Blocked by:** 03：拆解短配文并检查推断依据

**Status:** ready-for-agent

- [ ] 资料已经覆盖的问题先检索；仍缺信息时提出一个具体问题，说明它影响哪条主张及哪项口径，不要求用户代找已有材料。
- [ ] 每次调查最多一轮补证追问，补证仍不充分时停止并列出未解决项；前后共享总调用预算，不能通过恢复清零预算。
- [ ] 用户回答标为用户提供，只帮助确定口径；不能覆盖明确的图文内容或自动变成官方证据。存在冲突时保留双方依据并请求用户更正输入或保持待核对。
- [ ] 补证前后关联同一主张与记录，可看到检索条件和结论为什么改变；不能自动沿用不再适用的旧引用。
- [ ] 修改图片、配文、月份、范围或比较方式后，受影响结论立即失效；取消、重置和旧响应迟到不得恢复旧结论。历史结果明确标为历史。
- [ ] 浏览器完成「追问 → 补证 → 新结果」和「现场改范围 → 旧结果失效」；API 覆盖过期恢复、预算和冲突输入；真实模型单列一次必要追问及一次无需追问的案例。
- [ ] 固定评测增加补证前后对照，复验此前路径并同步文档状态。
