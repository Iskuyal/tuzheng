# 06：固定资料库内的反证与版本复查

**What to build:** 对初步结论中的明确风险进行一次追加检索，呈现支持、矛盾和不适用来源；冲突无法解决时保留分歧。

**Priority:** P1，条件增强，不阻塞参赛核心交付。

**Blocked by:** 05：带引用的修改建议与核心路径验收；适用的官方冲突／修订资料需核对并归档

**Status:** `ready-for-human`（2026-10-01）：**版本修订／版本替代已实现并完成整组真实模型实测**；「同口径冲突 → 来源存在分歧」因没有可核对材料未实现（等人找到材料）；「模型自主决定复查」按 [ADR 0002](../../../docs/adr/0002-revision-substitution-in-source-library.md) 改为程序侧确定性替代，不再按原勾选项做。

- [x] 先验证资料对的发布机构、口径、版本和修订关系；找不到合适公开材料时保持候选状态，不伪造官方版本或修订声明。**CPI 口径下全量检索未找到**（见 Comments 的调研记录）；改用用户批准的非 CPI 修订对（社会消费品零售总额环比），入库前逐字核对了两份官方发布页的附注 5 原句与数值，本仓库另行 `curl` 复验。
- [ ] 模型依据初步结论的具体风险决定复查或跳过；追加检索最多一次，仍遵守调查总预算并记录实际原因、命中及排除项。**未按原勾选项实现**：ADR 0002 决定复查由程序在结论阶段确定性完成（依据资料里的官方修订声明字段），不新增工具、不改预算（每轮 3 次／总计 6 次／4 轮／150 秒），也不让模型判定修订关系。
- [ ] 只有明确修订关系才允许版本替代；不同范围各自呈现，同口径冲突无法消解时标为来源存在分歧，不能用投票或日期新旧直接裁决。**前半句已实现**：`SourceDocument.revision` 必须指向库内发布、且必须真的改过同一比较方式与月份的数值（`verifySourceLibrary` 强制）；**后半句「来源存在分歧」未实现**——本轮没有任何可核对的分歧材料，不做无实测支撑的能力声明。
