# 06：固定资料库内的反证与版本复查

**What to build:** 对初步结论中的明确风险进行一次追加检索，呈现支持、矛盾和不适用来源；冲突无法解决时保留分歧。

**Priority:** P1，条件增强，不阻塞参赛核心交付。

**Blocked by:** 05：带引用的修改建议与核心路径验收；适用的官方冲突／修订资料需核对并归档

**Status:** needs-info

- [ ] 先验证资料对的发布机构、口径、版本和修订关系；找不到合适公开材料时保持候选状态，不伪造官方版本或修订声明。
- [ ] 模型依据初步结论的具体风险决定复查或跳过；追加检索最多一次，仍遵守调查总预算并记录实际原因、命中及排除项。
- [ ] 只有明确修订关系才允许版本替代；不同范围各自呈现，同口径冲突无法消解时标为来源存在分歧，不能用投票或日期新旧直接裁决。
- [ ] 复查改变结论后更新引用和修改建议，保留前后记录；资料不足时不提高结论确定性。
- [ ] 页面能展开复查前后证据；固定题集同时包含正确与错误初步结论，独立记录修正数、误改数和额外耗时。
- [ ] 真模型与替身证据分别归档；只有实测支持才将复查纳入视频和技术能力声明。
