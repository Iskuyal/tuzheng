# 02：证据不足分支与检索增益评测

**What to build:** 沿 CPI 图文主张路径增加来源缺失、口径不合、模糊图和工具失败分支，并用固定问题集证明检索是否改善有证据支持的判断。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 至少 10 个团队自制图文问题及独立期望，含正确、同比／环比错用、错月份、错范围、图上比较方式不明、来源缺失和干扰来源；输入与期望分开保存。
- [ ] 对每题用同一模型分别运行有检索和无检索，逐题记录结论状态、引用是否支持、无来源时是否克制、调用数、耗时与失败原因；不把预置或替身结果并入真实模型统计。
- [ ] 来源缺失、口径不合、引用无效、模型输出无效、工具失败或超时时，不输出确定来源结论；至少一条真实路径展示请求确认或停止。
- [ ] 本地测试验证引文 ID 只能来自本次命中资料、来源口径必须对齐、调用上限有效，浏览器验证证据与失败原因可见。
- [ ] 评测目标与未达标项逐项记录，按结果修改检索或缩小能力声明；同步阶段四和阶段五的演示材料范围。
- [ ] 预先锁定题集、独立期望、资料版本及比较配置；事实正确性、证据可追溯性和不适用来源识别分别报告。允许无检索答对、检索无增益或退化，不删除失败题；调整后重跑全组，区分开发题与预留题。
- [ ] 固定题集主张状态正确率至少 80%、虚构引用为零、无适用来源案例全部不下确定来源结论；保留逐题证据与在线运行次数。只有配对结果支持时才宣称对应维度的检索增益。
