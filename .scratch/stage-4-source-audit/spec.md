# 阶段四规格：图文证据调查与有依据的修改建议

Status: ready-for-human（核心01—05已验收；06版本替代已实现，剩余同口径冲突材料待人工提供；正文保留原规划）

## Problem Statement

当前已验收的 AI 负责读取图表中的明确增长率主张；确认后的计算、跨图比较和纵轴提示主要由程序执行。现有预置样例不会调用模型。参赛演示因此容易被理解为规则检查器，尚不能展示模型如何依据图文内容选择工具、检索公开来源并判断来源是否适用。当前 `claims[]` 读取契约遇到没有明确增长率主张的截图还可能返回空数组。

2026-09-28 确认的参赛优先级是**评委可复核的 AI 技术深度优先，读者体验其次**。先交付一条来源核验路径；不把规划中的 RAG、Agent 或工具调用写成已实现。

## Solution：一条端到端路径

1. 输入团队自制的 CPI 图表 PNG 和一段配文。首例图表只写「2025 年 12 月全国 CPI 上涨 0.8%」而不写比较基准；配文声称「比上月上涨 0.8%」。图上缺少同比／环比口径，因此图内不能单独判定配文真伪。样例必须醒目标为团队自制，不冒充官方图片。
2. 模型分别提取图中文字和配文主张，明确指标、地域、人群、月份、数值、比较方式及缺失项。与旧的增长率 `claims[]` 兼容，但不把「CPI 同比 0.8%」误当成从两个图上数值算出的增长率。
3. 模型在受限工具中选择下一步：检索公开来源、调用预定义数值比较、请求用户确认或停止。服务端验证工具名和参数；每轮最多三次工具调用，含恢复与可选复查在内的单次调查总计最多六次，最多一次补证追问。达到上限即展示已获得证据与未解决项。工具不得执行模型生成的代码，不得读取任意本机文件或访问任意网址。
4. 固定资料库只收录可公开引用、附原始链接与发布日期的国家统计局数据发布和术语解释。首批候选包括[2025 年 12 月 CPI 发布](https://www.stats.gov.cn/sj/zxfb/202601/t20260109_1962273.html)和[同比与环比解释](https://www.stats.gov.cn/zs/tjws/tjbk/202301/t20230101_1912960.html)。2026-01-09 发布的前者列出当月全国 CPI **同比 0.8%、环比 0.2%**。录入时保存短摘录、出处、发布时间、适用口径和内容指纹；另加入不同月份／范围的官方材料作为检索干扰项。运行时真实检索和排序，不以案例 ID 直接返回预设答案。
5. 结果逐项区分「图中可见」「配文声称」「公开来源记载」「系统推断」。首例预期：图表的 0.8% 因未标比较方式而需要确认；配文把 0.8% 说成「比上月」与该期官方发布的环比 0.2% 不一致。措辞限于**与所引国家统计局发布不一致**，不宣称证明所有现实数据或作者动机。
6. 界面展示模型选工具、工具输入摘要、检索命中、采用或排除的原因、计算结果、引用、耗时及停止原因；只在本次会话保留，不显示密钥。无适用来源、来源口径不合、模型输出无效或超时，都保持「来源待核对」并给出原因。

## User Stories

1. 作为评审，我想看到图和配文分别表达了什么，以便确认模型确实处理了多模态输入。
2. 作为读者，我想把一段配文拆成少量可核查主张，以便看到其中哪些部分已有依据。
3. 作为读者，我想知道数字正确时推断是否仍有缺口，以免把同比涨幅下降当成环比价格下降。
4. 作为评审，我想看到模型实际选择的工具、参数摘要与返回结果，以便复查工作流决策。
5. 作为读者，我想查看引用的原文、发布日期和口径，以便判断该材料能否支持当前主张。
6. 作为读者，我想在证据不足时补充一个关键字段，以便继续原来的调查。
7. 作为读者，我想让手填信息标为用户提供，以免它被当成官方来源。
8. 作为评审，我想现场更改月份或范围，以便观察旧结论失效和新调查过程。
9. 作为编辑，我想得到逐处附有证据的配文修改建议，以便决定是否采用。
10. 作为读者，我想保留尚未证实的部分，以免修改建议让表述变得过度确定。
11. 作为评审，我想比较同一组问题有无检索的结果，以便看到检索的实际作用与局限。
12. 作为评审，我想区分真实模型结果、替身测试和预置材料，以便评价已验证的能力。
13. 作为读者，我想在模型、检索或补证失败时看到停止原因，以便知道下一步需要什么。
14. 作为评审，我想在可选复查中看到支持和不支持初步结论的材料，以便判断复查是否有用。

## 后续垂直切片：首条路径验收后逐项扩展

- **03 主张拆解与推断检查（P0）**：一张图＋一段短配文，最多三条可核查主张，分别显示原文、直接陈述／推断、依据与未解决项。首批仅支持 CPI 比较基准、涨幅和价格水平，区分「与来源矛盾」与「现有证据不足以推出」。例如团队虚构的两个月同比涨幅下降图，不能单凭它确认配文中的「本月比上月便宜」；需适用的环比来源才能继续。观点和超出范围的因果推断标为不支持核验，不自动判错。
- **04 关键补证与恢复（P0）**：模型针对会影响结论的缺口提出一个问题并说明用途；已有资料能回答时优先检索。用户补充后沿原主张继续调查，输入仍标为用户提供。更改月份、范围、比较方式、配文或图片时，将依赖旧输入的证据适用性、结论与修改建议立即失效；历史记录可查看但不得当作当前结果。在途旧响应不能覆盖新调查。
- **05 有依据的修改建议（P0）**：只基于当前有效主张与证据生成一条建议配文，逐处显示原句、建议、理由和引用。允许用适用来源中的正确数字替换原文错误数字；不能引入证据未覆盖的数字或范围。对未解决主张保留限定词或建议删除，不替用户自动采纳。来源失效后同步撤回旧建议。
- **06 固定资料库内的反证与版本复查（P1）**：P0 完成且已有适合的来源对时，按初步结论中未消除的风险进行最多一次追加检索；记录支持、矛盾与不适用材料。只有可核查的修订说明才能把新版本作为替代，不能仅因发布日期晚就认定旧资料无效。无法消解的同口径冲突显示「来源存在分歧」。无复查需要时跳过，不能为了显示步骤而强制调用。

## Implementation Decisions：技术与证据边界

- **模型决策**：优先使用 Responses `function` 工具调用，由本机服务端执行只读检索、确定性计算和请求确认。当前提供方文档说明会透传 `function` 工具声明，但当前已用的具体模型是否稳定返回工具调用仍须在线验证；结构化模拟、替身测试或单次文本连接测试不算通过。若当前模型不满足，记录失败并评估可配置的兼容模型，不伪造工具轨迹。
- **检索策略**：先按指标、月份和范围寻找候选，再对短段落排序；不要按主张中的数值或比较方式把纠错材料提前过滤掉。术语定义不因缺少特定月份被排除。候选可用于解释差异，但结论采用的数值证据必须匹配正在核验的口径；不适用材料标出排除原因。是否增加向量检索以固定问题集的实测增益决定。
- **引用校验**：最终引用 ID 必须来自本次实际命中的资料，且显示原始 URL、发布日期、短摘录和适用范围。模型没有引用、引用不存在或与口径不符时，不生成来源一致／矛盾的确定结论。
- **资料分级**：用户手填或确认只算用户提供值；公开来源需要可追溯的发布机构与链接。数据发布与术语解释各自支持不同类型的判断，不能用定义页代替具体月份的数值来源。
- **安全与预算**：固定本地资料库，不在运行时抓取开放网络；设定调用次数、请求超时和输出大小上限。服务端负责数值比较和结果状态校验，模型只提出工具调用与有引用的解释。
- **旧路径**：单图增长率、跨图和纵轴路径继续可运行；阶段四不重写这些已验收的结果语义。
- **实现接缝**：复用现有观察校验、主张状态、确定性计算、证据卡与请求取消的约定；新增来源调查编排边界，组合图文读取、检索与计算。工具参数、引用与会话有效性必须由程序校验；「证据是否支持推断」仍是需要独立评测的模型判断，不能把结构校验通过等同语义正确。
- **过程展示**：呈现执行事件和简短行动理由；不要求或展示模型内部思维全文。先用卡片和可展开详情，不为此引入证据关系图编辑器或多智能体框架。

## Testing Decisions：验收路径与证据

1. **完整案例**：在页面上传自制 PNG、输入配文、调用真实模型并查看真实工具调用；结果正确分开图内未明确口径与配文和公开来源的冲突，引用指向本次命中的官方发布。模型、耗时、工具调用和结论有可复查记录。
2. **分支案例**：来源缺失、错月份、错范围、图上比较方式不清、模型未调用工具、工具失败与超时分别降级；任何一例不得虚构引用或把用户确认值标为官方数据。至少一例实际请求确认或停止。
3. **检索对照**：预先锁定至少 10 个团队自制图文问题与独立期望，覆盖正确、错误、歧义、无适用来源和干扰来源；03—05 增量加入推断检查、补证前后和修改建议案例，保留原题。固定模型、资料版本、输入和可比预算，除检索工具可用性及必要说明外保持其余配置一致。逐题记录状态、引用支持性、无来源克制性、工具选择、调用数、耗时与失败。模型可以凭已有知识答对；未知 URL 或不在提供材料中的正确记忆不算本次检索证据。
   功能门槛为预先固定题集上主张状态正确率至少 80%、虚构引用为零、无适用来源案例全部不下确定来源结论。检索收益分别报告事实正确性、证据可追溯性与不适用来源识别，不预设无检索必错。只有出现可复查的配对改进才宣称相应维度有增益，不能仅凭能显示引用声称准确率提高。保留无增益与退化题；调整提示或检索后必须重跑全组，并把开发中反复调过的题与预留题分开报告。真实在线记录必须明确重复运行次数和波动，单次小样本不外推通用准确率。
4. **分层验证**：纯函数和 API 替身测试验证边界，浏览器端到端测试验证页面路径与异常恢复；再单列当前真实模型的视觉读取、工具调用和检索结果。运行 `npm test`、`npm run test:e2e`、`npm run build`，并按每次实测更新 [`docs/PHASES.md`](../../docs/PHASES.md)。预置案例、固定评测和真实模型结果分别计数。
5. **接缝与回归**：沿用现有 Express API 行为测试与 Playwright 320／390／1280 页面路径，优先验证输入到结果、补证恢复、换图失效和引用展示；仅在数值计算、引用约束和预算规则需要独立定位时增加单元测试。真实模型评测由独立期望逐项复核，不能只让生成答案的模型自己评分。05 收尾时复跑完整集及旧单图／跨图路径。
6. **可选复查对照**：06 用预先锁定的正确结论和有缺陷结论分别比较复查前后，记录纠正错误和引入错误的数量、依据与额外耗时；未经验证不得宣称复查提高可靠性。

## Out of Scope

- 首条路径不接入任意网页实时搜索、CSV 上传、公开数据 API、PDF 批量处理或多智能体框架。
- 不把 CPI 案例扩写成对所有统计图的自动事实核查。
- 不把国家统计局链接、预置观察或本机替身输出包装成实时模型结果。
- 通用因果判断、平均数／中位数等其他统计专题、开放网络找反证、自动发布改写、完整证据关系图和假设敏感性留作后续候选；本轮不预先承诺。
