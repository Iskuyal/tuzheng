# 04：完成窄屏浏览器端到端验收

**What to build:** 手机用户可以在一张图上逐条查看主张和证据、确认或更正读数、查看结论与操作记录，并能重置本次审计。

**Blocked by:** 03：增加会话审计记录和整份重置

**Status:** ready-for-agent

- [ ] 增加可通过根目录 npm 脚本重复运行的自动化浏览器测试，使用预置示例，不依赖真实 API Key。
- [ ] 测试在 320px 和 390px 视口走完整流程：逐条查看证据及其状态、确认收入主张、更正利润主张、检查三类结果、查看记录并重置。
- [ ] 自动化断言利润主张的更正不会改变收入主张，缺证据的用户数主张仍为“需要确认”。
- [ ] 窄屏核心操作可触达、可读，页面没有横向溢出。
- [ ] 将实际浏览器验收结果和未通过项记录在路线图中；不把该测试写成真实在线模型验收。
