# 03：增加会话审计记录和整份重置

**What to build:** 读者可以查看当前审计会话中各项主张的确认、更正和重算记录，并在需要时清除本次状态。

**Blocked by:** 02：完成逐条确认、更正和局部重算

**Status:** ready-for-agent

- [ ] 操作记录显示主张、动作、发生变化的值和对应结果，便于回看每项结论如何形成。
- [ ] 记录只保存在当前会话，不写入浏览器存储、本机文件或服务端持久存储。
- [ ] 重置操作恢复当前图片最初载入的观察值，并清除所有确认、更正、结果和会话记录；模型设置页保存的配置不属于本次审计。
- [ ] 切换图片、刷新或离开当前审计后，不会恢复先前会话的记录。
- [ ] 自动化行为测试覆盖事件顺序、主张归属、重置前后状态和记录清除。
