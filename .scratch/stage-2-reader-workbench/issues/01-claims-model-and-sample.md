**Blocked by:** None (can start immediately)

**Status:** completed

- [x] 预置样例与模型读取只输出 `claims[]` 中各主张的原文、图上观察、图内证据和无法辨认项；工作台单独建立确认或更正值、确认状态和确定性计算结果，模型不输出结论。
- [x] 原始观察和用户确认值分开保存，证据摘录在数值更正时不被覆盖。
