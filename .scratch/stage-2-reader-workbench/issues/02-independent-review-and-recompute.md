## Comments

**2026-09-26 缺陷与修复（布局，不影响上述行为验收）：**读者截图显示主张卡底部的 `确认并计算此主张` 按钮与它下方的说明文字重叠。原因是按钮宽度只靠阶段一 `.observation-form` 的 flex 列撑开，本任务引入的主张卡用普通块容器承载按钮，按钮收缩为文字宽度；同时 `.confirm-hint` 的 `-6px` 上边距此前是被表单 13px 的 flex 间距抵消的，在主张卡里没有任何东西抵消它，文字因此压到按钮上（1441px 视口实测横向重叠 35px、纵向 6px）。修复：`.confirm-button` 增加 `width: 100%`，并为主张卡补 `.claim-observation-body .confirm-button { margin-top: 12px }` 与 `.claim-observation-body .confirm-hint { margin-top: 7px }`。

修复后实测证据：1441 / 800 / 390 / 320px 视口下三条主张的按钮均随容器撑满、提示与按钮间距 8px、无重叠、无横向溢出；阶段一单主张表单间距不变。`npm test` 39/39、`npm run build` 通过；三个单主张样例重跑结果与阶段一预期一致。此前记录的走查只断言了阶段一表单的按钮不盖住编辑框，未覆盖主张卡的操作区，本次把该断言范围记住：改动表单或主张卡的操作区时，需要同时确认按钮不被任何文字压住。
