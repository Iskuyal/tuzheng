# 02：完成逐条确认、更正和局部重算

**What to build:** 读者可以独立核对、确认或更正一条主张，并看到由该主张已确认输入计算出的结果。

**Blocked by:** 01：建立单图 `claims[]` 结构和三主张预置样例

**Status:** completed

- [x] 用户确认一条主张后，其他主张的观察值、确认状态和结果保持原样。
- [x] 用户更正利润主张的 2025 年读数为 100 后，只重算利润主张并显示“图内矛盾”；其原始观察仍可复查。
- [x] 收入主张可显示“图内一致”；更正利润主张不会改变其结果。
- [x] 用户数主张因新值缺少图内依据保持“需要确认”；即使用户补入数字，也不显示“图内一致”或“图内矛盾”。阶段一“看不清”样例的标签仍有图内对应位置，补值后的既有结果保持不变。
- [x] 自动化行为测试覆盖逐条确认、单条更正的结果隔离、三类状态和缺证据降级。
