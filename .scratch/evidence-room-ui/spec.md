# 证据阅读室 UI 落地

状态：主路径及全站主题补齐已完成本地离线验收；2026-10-18 根据用户指出的设置页遗漏，扩展并完成全部四个路由及主要状态，任务见 [02-all-routes](issues/02-all-routes.md)，结果与独立视觉意见见[全站报告](../../docs/reviews/2026-10-18-evidence-room-full-ui.md)。用户已确认按 2026-10-17 的已审阅设计实施。真实模型、真机与团队人工验收不在本次通过声明内。

第一用户为普通截图读者；第一项任务完成开始页到来源核验的端到端路径，以及所需窄屏、补证、采用后失效、错误恢复和原图预览；第二项任务补齐图内工作台与模型设置，检查实际路由表中的全部页面及关键状态。设计依据为 `docs/design/evidence-room-2026-10-17/`。保留图内审计和设置的既有功能，不改模型协议、服务端契约、资料库与冻结评测包。

成功标准：

1. 开始页区分来源样例、自带图文来源核验和图内检查；载入/选图均不发模型请求。
2. 工作台能接受首页图片，核验使用现有端点；来源、主张、建议和工具记录来自实际响应，不将静态示例装为结果。
3. 原图可放大、滚动/拖动并键盘关闭；从模型设置返回保留当前输入；取消新选图不丢失仍显示的图片。
4. 旧结果在输入变化、采用或重查时失效；补证保留用户提供身份；失败可编辑和重试；采用后显示当前配文及历史入口。
5. 320/390/桌面渲染可读，核心操作可用键盘完成；既有图内/设置路径继续通过浏览器回归。
6. 记录实际截图、行为测试、构建、独立视觉评审和证据限制；离线替身不算真实模型复验或人工验收。
7. 全部四个路由及主要计算/弹层/配置状态采用统一主题；使用假配置检查 file/env、手动连接与清除待保存，不覆盖用户配置。

计划：保存当前实现基线 → 修改 Vue/CSS 与交接/返回状态 → 针对新交互及确认缺陷先重现后修复 → 全量既有检查及宽窄屏真实渲染 → 更新设计、路线图与交付记录。
