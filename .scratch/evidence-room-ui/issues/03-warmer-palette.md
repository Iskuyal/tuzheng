# 03：减少大面积浅白，增强纸色与分区层次

Status: completed
Blocked by: none

用户反馈现有 UI 过白。沿已确认的“证据阅读室”方向做可逆配色微调，覆盖四路由共享主题；页面文案、信息顺序、操作、路由与配置契约保持现状。按 UI skill 的轻量样式分支执行，不重启整套设计或独立评分。

## 验收项

- [x] 保留当前四路由及关键状态的真实渲染基线。
- [x] 更温暖的纸色画布、奶油色内容面、深墨绿导航与鼠尾草绿辅助区形成可见层次。
- [x] 四路由桌面/窄屏及主要状态不溢出；正常页 200% 字号检查通过；导航与正文可读。
- [x] 构建及相关浏览器操作回归通过，保存当前截图与内容指纹。

成功标准是减少浅白的连续面积，同时保持可读和原有路径可用；不以调色结果宣称模型、真机、用户研究或此前静态评分继续适用于当前版。

本轮 36 画面、12 正常页字号、32 组配色/焦点检查与构建通过；全量浏览器 140 通过/1 跳过，焦点级联修正后定向键盘回归 5 通过/1 不适用跳过。最终截图、指纹、原始配色问题与证据范围见[配色微调报告](../../../docs/reviews/2026-10-18-evidence-room-tone.md)。
