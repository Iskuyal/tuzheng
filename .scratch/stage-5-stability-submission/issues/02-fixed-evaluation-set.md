# 02：扩充自制固定样例并形成可重复评测

**What to build:** 团队能用固定图片和独立预期重复检查读者实际看到的图内结果、跨图口径与纵轴提示。

**Blocked by:** None (can start immediately)

**Status:** completed

- [x] 自制样例总量至少 18 张，覆盖算术矛盾、图内一致、模糊值、缺证据、跨图冲突与口径不合、纵轴截断和轴范围不明。
- [x] 每张样例有独立预期及使用许可说明；预置观察与真实模型读取明确分开。
- [x] 提供根目录可重复运行的评测入口，检查结果状态、公式或差值、证据与不确定原因，并输出通过与失败清单。
- [x] 至少一处有意破坏的规则或期望能使评测失败；正常状态下完整测试与构建通过。
