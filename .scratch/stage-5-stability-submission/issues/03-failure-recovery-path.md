# 03：完成模型与输入失败后的读者恢复路径

**What to build:** 当模型不可用、超时、输出结构不符或图片无效时，读者能看到真实原因并安全地重试或改用明确标记的自制样例。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 未配置、上游失败、超时、结构错误、图片格式或大小错误具有可区分的页面提示和下一步操作。
- [ ] 失败不留下旧模型观察的新结论，不把预置数据或上一轮结果说成当前模型输出。
- [ ] 在途请求取消、换图与重试不会写回过期结果；必要行为由 API 与浏览器测试覆盖。
- [ ] Windows 根目录 `npm install`、`npm run dev`、完整测试与构建可复现。
