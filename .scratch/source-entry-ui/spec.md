# 来源核验主入口与信息层级

日期：2026-10-03。依据 [PLAN](../../PLAN.md)、[模拟评委报告](../../docs/reviews/2026-10-02-mock-judge-review.md)与本次用户要求。

## 一条用户路径

截图读者／评委从首页发现来源核验 → 进入现有 CPI 团队自制样例的图片与配文输入态 → 主动运行 → 查看逐条结论和依据 → 必要时补证或明确采用建议。进入、刷新、选预设均不自动调用模型。

本次保留像素风、图内上传、已有图内／跨图／纵轴样例与证据语义。来源页先讲任务、结果和覆盖边界，技术机制、统计与实际工具轨迹按需展开。设置页分别呈现历史实测和文档预设；测试连接只证明所测协议结构，历史成功不能当作当前配置验收。

## 验收

- 320／390／1280 视口：入口可用、无横向溢出，图片／配文保持，深链刷新正确。
- 实际 Tab／Enter／Escape 操作覆盖导航、上传、确认、依据展开、补证和采用建议；检查可见焦点、控件标签与状态反馈。
- 异步样例不覆盖下载期间的新输入；模型响应失效与历史边界继续保持。
- 生产构建在记录设备、浏览器、网络和 CPU 配置后重复采样，保存逐次原始结果和截图，修复实际观察到的问题。
- 相关 e2e、构建、文档链接检查通过。所有模型路径离线拦截／替身，真实模型调用为 0。

读屏、真实手机、真实模型与正式材料发布不由本次离线证据证明。实时工具事件流另列后续候选，不以计时器模拟工具步骤。
