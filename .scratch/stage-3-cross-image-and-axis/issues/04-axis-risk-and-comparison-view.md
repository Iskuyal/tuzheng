# 04：柱状图纵轴风险与从零起点对照视图

**What to build:** 柱状图纵轴不从零开始时提示「可能误读」，并用已确认数值重画从零起点的对照图。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 轴最小值 > 0 且两个数值都可读时显示「可能误读」，并给出原图轴范围与从零起点的高度比。
- [ ] 轴信息缺失时显示「需要确认轴范围」，用户可手填轴最小值后重新判断。
- [ ] 对照视图用已确认数值与轴起点确定性重画两根柱子，原图轴范围与从零起点两版并排；不调用模型。
- [ ] 文案明确「可能误读」是呈现方式风险，不是造假判断；从零起点差异不大时也要如实说明。
- [ ] 自动化测试覆盖风险规则、轴缺失降级、高度比计算与对照视图的渲染数据。
