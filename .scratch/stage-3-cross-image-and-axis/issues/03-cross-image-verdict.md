# 03：跨图数值一致／冲突判定与证据

**What to build:** 口径确认后给出跨图结论：两侧已确认数值的增长率一致或冲突，并列出两张图各自的原图文字依据。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 只使用两侧**已确认**的读数计算增长率，与阶段一、二同一套确定性规则。
- [ ] 结论只有「数值一致」「数值冲突」「待核对」三类；冲突时给出两侧的计算值与差值。
- [ ] 证据区并排显示两张图对应的原文摘录与来源标记（预置示例／模型读取／用户更正）。
- [ ] 明确写出这只比较两张图是否自洽，不代表现实数据真伪，也不判断作者动机。
- [ ] 自动化测试覆盖一致、冲突、口径不清三种结果与证据字段。
