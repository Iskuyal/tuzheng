## Comments

**2026-09-26 实现与实测：**`shared/cross-image.ts` 增加 `auditObservationFrom`（用确认过的核对值组装一侧的审计观察值）与 `compareCrossGrowth`（复用阶段一的确定性增长率规则逐侧计算后比较）：两侧都能算时按差值判「数值一致」或「数值冲突」，任一侧算不出就停在「待核对」并分别说明是哪一侧缺什么。界面在跨图区新增结论卡：状态胶囊（数值一致／数值冲突／待核对）、结论文字（含两侧计算值与相差百分点）、两侧原图文字摘录与来源标记并排，以及「只比较两张图彼此是否自洽、不代表现实数据真伪、不判断动机」的边界说明。

判定只读**已确认**的值：多主张路径取 `confirmedValues`，单主张路径只在表单已确认时取当前观察值，对照图取自己的已确认值——没有确认的读数不参与。

实测（浏览器）：基准图对「说法对不上」那张，两侧分别确认读数后显示「数值冲突：当前图算得 25%，对照图算得 50%，相差 25 个百分点」，证据区并排列出两张图的 80／100 与 80／120 摘录与来源标记；换成「说法对得上」那张后变为「数值一致：两张图按各自已确认读数都算得 25%」；换成「范围不同」那张则不给结论，闸门保持「还差 范围／人群……待核对」。1707px 与 320px 无横向溢出。

测试：`npm test` 69/69 通过（新增 4 条跨图判定用例：一致、冲突含差值、一侧缺读数降级、取不到主张返回 null）；`npm run typecheck`、`npm run build` 通过。
