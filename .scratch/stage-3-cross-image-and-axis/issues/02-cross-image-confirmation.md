# 02：第二张图、口径配对与确认

**What to build:** 读者能把第二张图放进同一次核对，看到系统给出的候选配对与口径四要素，并逐项确认。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 同一次会话可放第二张图（样例或上传），标注为「对照图」，切换或移除它不影响当前图的确认状态与结果。
- [ ] 系统按指标名给出候选配对（去空白、全半角、大小写后相等），并在界面上展示两侧的指标、时间、单位、范围。
- [ ] 四要素齐备且一致时才能进入比较；任一缺失或不一致时显示「待核对」并列出差在哪个要素。
- [ ] 用户可对单个要素点「确认一致」补上读不出的信息，确认留痕且只影响本次会话。
- [ ] 对照图未确认的读数不参与比较，保持「待核对」。
- [ ] 自动化测试覆盖配对归一化、四要素三种走向与「未确认不比较」。
