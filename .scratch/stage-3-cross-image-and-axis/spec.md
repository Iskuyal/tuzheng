# 阶段三规格：跨图口径确认与纵轴对照

Status: ready-for-agent

## Problem Statement

现在一次只检查一张图。读者刷到两张「同一个指标」的截图（转发图与原始图、两个季度的海报）时，无法知道两张图的数字是否冲突；看到柱状图纵轴不从零开始时，也无法判断差异被放大了多少。图内结果本身已经可靠，缺的是**跨图的口径核对**和**呈现方式的风险提示**。

## Solution

在当前会话里允许放入第二张图作为对照图，并把一张图的主张与另一张图的主张按**口径四要素**（指标、时间、单位、范围／人群）配对。只有四个要素都确认一致时才输出「数值冲突」或「数值一致」；任一要素不清楚、缺失或不一致时保持「待核对」，并明确列出还差哪个要素、需要用户确认什么。

柱状图在轴最小值不为零时给出「可能误读」的视觉风险提示，并用**已确认的数值**重画一张从零起点的对照图，同时展示原始轴范围与从零起点的柱高比；不判断作者动机，也不把「可能误读」写成结论。

## User Stories

1. 作为读者，我想把第二张图放进同一次核对，看到两张图对同一指标说了什么。
2. 作为读者，我想知道两张图能不能比：指标、时间、单位、范围是否一致，哪个对不上。
3. 作为读者，我想在两图比对前确认口径，而不是被系统直接判成冲突。
4. 作为读者，我想在口径不清楚时看到「待核对」和缺失项，而不是一个看起来确定的结论。
5. 作为读者，我想看到两张图各自的原图文字依据，以便自己复核。
6. 作为编辑，我想知道柱状图纵轴是否截断、差异被放大了多少，避免发布引起误读的图。
7. 作为读者，我想看到按确认数值重画的从零起点对照图，而不是只能凭感觉判断。
8. 作为读者，我想让「可能误读」和「事实矛盾」分开显示，不把视觉风险写成造假。
9. 作为手机用户，我想在窄屏上完成两图核对与对照图的查看。
10. 作为读过阶段一、二的读者，我想原来的单图路径和预置样例继续可用、结果不变。

## Implementation Decisions

- **口径四要素**：主张新增 `metric`（指标名，如「营业收入」）与 `scope`（范围／人群，如「全国门店」，可为空）；时间与单位沿用每个观察点的 `period` 与 `unit`。预置样例与视觉模型都只提供原文字段，不提供判定结果。
- **第二张图**：同一次会话最多两张图，分别是「当前图」和「对照图」；对照图可以来自内置样例或上传。切换或移除对照图不影响当前图的确认状态与结果；两图各自的确认状态、结果和记录互不影响。
- **配对**：系统按 `metric` 文本相等先给出候选配对（同名度归一化：去空白、全半角、大小写）；找不到候选时提示用户改选主张，不猜。
- **判定**：四个要素齐备且都一致 → 比较两侧**已确认**读数的增长率为「数值一致」或「数值冲突」；任一要素为空或两侧不一致 → 「待核对」，并列出缺失或冲突的要素名。用户可以对某个要素点「确认一致」来补上模型读不出的信息；用户确认要留痕，且只影响本次会话。
- **不受用户的更正影响**：另一张图的读数只有在该图被确认后才参与比较；未确认时保持「待核对」，不读草稿值。
- **纵轴风险**：柱状图的观察值可带 `axis`（`label`／`min`／`max`／`unit`，都可为空）。轴最小值 > 0 且能读到两个数值时给出「可能误读」提示，并给出从零起点的高度比。轴信息缺失时提示「需要确认轴范围」，用户可手填轴最小值。
- **对照视图**：用已确认数值与（可手填的）轴起点确定性地重画两根柱子，并排显示「原图轴范围」与「从零起点」两个版本；不调用模型。
- **结果等级**：跨图只用「数值一致」「数值冲突」「待核对」；纵轴只用「可能误读」「从零起点差异不大」「待核对」。跨图结论与纵轴提示都不代表现实数据真伪。
- **会话范围**：对照图、口径确认、跨图结果与纵轴提示都只存在于当前会话；重置审计会清空它们，并回到当前图最初载入的观察值。

## 样例（团队自制）

- 跨图三对：**一致**（两张「营业收入」图都是 80→100，时间与单位相同）、**冲突**（同指标同时间，一张 80→100、另一张 80→120）、**待核对**（同指标但范围不同或未标注，例如「全国门店」对「直营门店」，或一侧缺时间）。
- 纵轴三张：**从零起点**（正常对照）、**截断纵轴**（最小值 80，视觉差异被放大）、**起点不明**（轴标签看不清，应提示需要确认）。
- 每个样例配独立的预期结果，写在 `samples/expectations.json`；图片仍以 SVG 保存供页面展示、同内容 PNG 供上传与模型读取。

## Testing Decisions

- 纯函数层：口径对齐与判定（四要素齐备／缺失／不一致三种走向）、候选配对的归一化匹配、纵轴风险规则与从零起点高度比。
- 服务端：结构化观察校验接受带 `metric`／`scope`／`axis` 的 `claims[]`，拒绝形状错误；预置样例 API 返回口径字段且不附带判定结果。
- 浏览器端到端：在两图路径上完成配对、口径确认、冲突与「待核对」两种结果，并查看对照图；在 320px 与 390px 视口确认无横向溢出、核心操作可触达。
- 沿用现有边界：完整验收不需要 API Key。

## Out of Scope

- 图文核稿（粘贴正文与图表对齐）：需要正文输入与来源归类，放到阶段四与来源核验一起做。
- 三张以上的多图比对、跨图单位换算（不同单位一律「待核对」，不做自动换算）。
- 真实来源核验、CSV 导入、RAG、导出。
- 自动框选与像素级定位。
