# 分享来源核验结果

日期：2026-11-10。依据 [PLAN](../../PLAN.md)（第 25 行「再将解释分享给朋友」、第 82 行导出页「不把模型建议写成事实结论」）、[领域术语](../../CONTEXT.md)（主张、来源结论、引用角色、未解决项、历史结论、修改建议）与本次用户要求。

## 一条用户路径

已有一份**当前有效**的来源核验结果 → 在结果区点「分享这次核验」→ 弹层显示一份纯文本摘要 → 点「复制摘要」写入剪贴板（剪贴板不可用时选中摘要文本并提示按 Ctrl+C）→ 按 Escape 关闭弹层，焦点回到触发按钮。

摘要只描述这一次核验：标题、边界声明、逐条结论（五类来源结论之一加一句说明）、引用来源与引用角色、数值对照、未解决项、未展开主张、补证记录、停止原因，最后一段是 `摘要指纹：` 加 16 位十六进制（复用既有 `fnv1a64`），指纹行之后再跟一行说明「指纹由摘要正文计算；文字被改动后指纹即不同。」——指纹行不是全文最后一行。接收者可以据此核对文本没有被改动，但指纹只证明文本未改，不证明摘要内容本身正确。

分享只把文本交给用户自己的剪贴板：不生成服务端短链或图片化海报，不接入社交平台 SDK，不上传到任何第三方，也不新增后端路由。分享的是当前结果；已因输入改动或重新核验作废的**历史结论**不参与。

## 验收

- 320／390／1280 视口：结果区入口与弹层可用、无横向溢出，摘要可滚动读完。
- 真实 Tab／Enter／Escape 完成打开 → 复制 → 关闭；关闭后焦点回到触发按钮，弹层打开期间焦点不落到背景内容。
- 剪贴板不可用时降级可用：不报「已复制」，改为选中摘要文本并提示 Ctrl+C。
- 摘要是纯文本、确定性生成：同一份结果重复生成逐字相同；单测覆盖各节内容与指纹。
- 口径：边界声明「仅核对当前主张与适用的收录来源；未确认整张图、原始数据或制作过程的真实性。」原文写进摘要；模型修改建议只标为「尚未采用」的参考，不写成事实结论；用户补充的口径值标为「用户提供」，不是官方来源。
- `npm run typecheck`、`npm test`、`npm run docs:check` 通过，`e2e/source-share.spec.ts` 通过。所有模型路径离线拦截／替身，真实模型调用为 0。

不新增后端路由，不做服务端短链、图片海报与第三方上传。读屏软件实际朗读、真机、以及「接收者据此相信摘要」都不由本次离线证据证明。
