## 视频边界

B站页面标题与作品相符，元数据为399秒、1920×1080，符合时长和源分辨率要求；平台转码后与本地398.233333秒MP4不逐字节比对。页面有“试看30秒/登录享高清”提示。游客默认在约61秒弹登录窗口并暂停；使用页面正常关闭按钮后，再点击播放可继续到70秒，无媒体错误。评委遇弹窗可关闭继续，高清按B站页面提示登录。本轮没有完成从头到尾的游客连贯播放或全片听审，不能声称已验证全程无提示，详见[本轮报告](../reviews/2026-11-15-pre-upload-recheck.md)。

主视频仍是此前确认成片，未展示新增结果分享，分享由两份PDF及离线证据说明。B站简介提到“必要补证”，原实录的缺口径案例实际没有触发补证/恢复，文档保留这一边界；建议简介改为“演示图内自检、配文与来源核对、修改建议和待核对状态；系统另支持必要补证”。这属于内容说明优化，本轮没有登录或编辑B站账号。

## 运行和最终操作

Windows安装Node.js 24及npm，解压源码，在根目录执行`npm ci`、`npm run dev`，打开`http://127.0.0.1:5173`。预置图内样例可离线使用；新图片读取/来源核验需要自己的合法模型配置。评审使用环境变量时按`.env.example`整套填写，详细见`docs/MODEL-CONFIG.md`。公网应用演示是可选项，当前未提供可核验应用站点，不填示例地址。

1. 核对包外`ZIP-SHA256.txt`，确定使用11月15日的新ZIP；不要从旧包取技术报告或源码。
2. 上传新ZIP到网盘，取得实际链接与提取码，用未登录窗口检查可访问。
3. 在正式表单第6项单独上传4页介绍PDF，第7项填写上述B站播放页，第5项填完整作品网盘链接。
4. 由指定一人核对UID、手机号、团队/学校及全部链接后提交，保存成功回执。官网说明提交后不得修改，特殊情况需联系组委会。

本轮没有填表、上传网盘或点击提交。12题人工签字、正式三臂真实模型评测及读者研究保持原记录状态，离线检查不代签这些事项。
