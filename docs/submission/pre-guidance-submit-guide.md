核对日期：2026-10-29。依据[正式赛道页面](https://www.boxuegu.com/matchTrack/detail/?id=10037)及[预指导表单](https://f.kdocs.cn/ksform/w/write/YEH4ZvlT#routePromt)，详细对照见[要求记录](../competition/submission-requirements-2026-10-29.md)。

这次金山表单只用于预指导，页面截止为 **2026-10-31 15:00:00**。每队仅提交一次，由队长或团队指定的一名成员负责。完成预指导后，仍须在 **2026-11-18** 前按赛事个人中心的省赛正式入口另行提交；官网未在本次读取中给出正式截止时分。

完整作品ZIP由固定提交导出，生成后位于本机 `.cache/submission-ready-2026-10-29/<完整SHA>/`。内含介绍PDF、技术PDF、有声视频、完整源码ZIP、运行说明、填写参考及哈希清单。包名建议为 `岭南凤翔团队_图证_C组_预指导材料_20261029.zip`；这是本项目整理建议，页面未规定统一命名。不要将这个完整ZIP上传至第6项，那里只选择作品介绍PDF。

需要重建时，在干净提交上先按[固定交付工具](closeout/README.md)生成同SHA交付包，再运行 `python -X utf8 docs/submission/closeout/create-pre-guidance-package.py`。两个工具均拒绝覆盖已有目录，以保留此前材料及哈希。

## 提交前先取得两个真实链接

1. 将完整作品ZIP上传至自己的主流网盘，生成可访问分享链接。建议长期有效；若有提取码，在链接后一起填写。用另一浏览器或未登录窗口确认对方能够访问、下载完整包。
2. 将有声MP4上传至已有的B站、抖音等公开视频账号，等待审核并确认公开视频能够播放。复制视频播放页的 `https://...` 链接。第7项不能填本地路径、GitHub文件下载地址或百度网盘视频链接。

本轮尚未替用户上传网盘或视频平台，因此这两个链接仍待生成，不能用示例URL代替。公开视频链接和网盘链接用途不同，即使ZIP中已有视频，也仍要单独填写第7项的公开视频地址。

## 登录后按七项填写

| 表单项 | 填写或选择 |
| --- | --- |
| 1. 成员uid | 指定提交人从自己的赛事账号核对实际UID；找不到时向报名负责人确认，不填手机号或猜测的编号 |
| 2. 团队名称 | `岭南凤翔团队` |
| 3. 学校 | `岭南职业技术学院（清远校区）` |
| 4. 联系人手机号 | 填已经核对的真实联系人号码；无需发到聊天或写入仓库 |
| 5. 完整作品链接 | 第一步生成的网盘分享链接，附实际提取码（如有） |
| 6. 作品介绍文档 | 选择本指南上方的4页作品介绍PDF；页面最多1个附件、单个100MB以内 |
| 7. 视频地址 | 第二步取得的、已公开且可播放的视频页面链接 |

如果个人中心的学校名称与校区分开填写，以账号正式登记名称为准核对，不擅自更改报名信息。该表单没有单列作品名和组别，作品名“图证”、C组及两位成员已经写入介绍PDF。

## 点击提交前检查

- UID、团队、学校、手机号属于同一队伍及指定提交人；确认其他队员没有重复提交。
- 第5项能下载完整ZIP；第6项是作品介绍PDF，能打开且七方面内容齐全；第7项是公开视频平台链接，能播放。
- 包中技术PDF为17页，视频为398.233秒、1080p、有普通话讲解；原创及此前未发表/未获奖声明来自用户明确确认。
- 不填写虚构公网应用地址、测试账号、获奖经历或真实模型密钥。图证本机离线体验不需模型Key，主动调用模型需另行配置及预算。

确认后由指定成员在 **10月31日15:00之前** 点击提交。保存成功页面、时间、附件名称、实际分享链接及文件SHA-256；含手机号或UID的回执留在本机私有目录，避免提交到公开仓库。没有成功提示及回执，就不能记为已提交。

## 预指导之后

继续关注指导反馈。省赛正式入口在缴费后的赛事个人中心所报赛项中；不能把此金山表单当作最终省赛提交回执。正式提交前重新核对入口、当期限制、最终文件和链接。完整三臂模型评测或真实读者研究不是本次读取到的表单字段，本次不为填表额外运行付费评测，也不将未完成研究写成已取得成绩。

正式提交后，按官网要求不再自行修改已提交材料；确需调整时联系组委会处理，不直接替换分享链接中的文件。
