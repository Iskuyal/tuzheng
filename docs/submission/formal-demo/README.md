## 配音与编辑

从 [配音稿](voiceover-draft.md) 和 [章节字幕](chapters.srt) 开始。先把无声 MP4 导入剪辑软件，再按时间轴录人声；稿件可按个人语速改写。来源标记已在画面中，章节 SRT 可作为剪辑定位参考，不必整段作为字幕显示。

原始素材另存为[连续主录屏](../tuzheng-formal-demo-uncut.webm)和[独立格式恢复镜头](raw-input-recovery.webm)，与本机 `.cache/formal-demo-2026-10-16/` 的两个原件逐字节一致。原始片段和最终片段的时间映射保存在视频检查 JSON；原件哈希也在其中。录制和剪辑使用系统 Edge / Python Playwright / FFmpeg，成片没有加速操作或模型等待。

离线重新导出（使用现有原始素材，不调用模型）：

```powershell
python -X utf8 docs/submission/formal-demo/render.py
python -X utf8 docs/submission/formal-demo/check-origin-labels.py
```

录制代码是本次固定批次的原始工程，不是无授权重录入口。`capture-server.mjs` 使用用户为本次提供的官方密钥，放在 LocalAppData 的专用临时配置中；密钥不在本目录、视频或证据日志中。录制进程已关闭，专用密钥配置已清理，主用户配置保持原样。已完成批次拒绝重新启用，新增付费录制必须新建批次与授权。

角标检查额外使用 Python Pillow 与 FFmpeg，直接抽取成片右上角实际像素，不只校验 ASS 文本；检查不调用模型。
