## 4. 公网在线演示：本次决定不提供

赛事文档把「可公网访问的在线演示地址」列为**可选加分项**，并要求提供后「评审期间须保持服务可用」。本次决定不提供，理由与所需条件如下：

**为什么不提供**

1. 本应用默认把模型密钥保存在**当前 Windows 用户的 LocalAppData**；2026-10-02 增加显式启用的服务端环境配置，密钥仅在内存使用，见[模型配置说明](../MODEL-CONFIG.md)。服务仍只监听 `127.0.0.1`。环境兼容不提供用户隔离与费用控制，公网演示仍需独立验收。
2. 公网服务意味着持续可用性与费用承担（模型调用按量计费），本次提交没有安排运维与预算。
3. 赛事允许「Public 仓库 + README 说明」的离线复现路径；离线功能（样例审计、跨图与纵轴、固定评测、三视口界面）**不需要任何密钥**即可运行，评审可以在本机完整看到除真实模型调用以外的全部行为。

**如果以后要提供，需要先满足**

- **密钥方案**：平台侧代管一份受限额度的密钥（或一次性体验额度），服务端只从服务器环境注入，绝不下发到页面；设置页在服务端代管模式下禁用自定义密钥。
- **可用性**：至少覆盖评审期的常驻实例、健康检查、每日费用上限与熔断（超出限额时降级为「未配置模型」提示而不是报 500）。
- **限流与滥用防护**：按 IP／会话限流，单次调查的预算常量（每轮 3 次、总计 6 次、150 秒）保持不变。
- **数据政策**：上传图片只在请求期间驻留内存，服务端不落盘、不记录配文原文；需要写明隐私说明。
- **记录**：按赛事要求另记服务可用性与密钥方案（即本节扩写为独立记录）。

在这些条件满足之前，README 只提供本机启动方式，不发布公网地址。
