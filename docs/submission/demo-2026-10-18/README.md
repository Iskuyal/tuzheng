## 实际画面与边界

系统 Edge / Python Playwright 自动操作实际 Vue 生产构建和产品 API，原生 1920×1080。全部底图来自本次实际浏览器录制，没有生成界面、拦截响应、预置模型答案或复用旧版 AI 画面。团队自制图片作为输入，首页静态示意仍明确标记为预览；上传读数及来源结果来自本次真实请求。

展示内容：实际读出 80、100 和标题“增长 40%”，人工确认后程序计算为 25%；将 100 改为 96，重新计算为 20%，改回 100 后为 25%。来源段展示 CPI 配文的环比 0.8% 与所引发布的环比 0.2% 不一致，以及引用、实际工具轨迹、逐处建议和采用后旧结果失效。重复的图内观察与未明确比较方式的待核对状态保留。

**本次口径不明案例没有触发追问表单，也没有执行 resume。** 该段按真实结果命名为“口径不明时保留待核对”，不称补证恢复成功。格式恢复只到合法图片输入，0 次模型请求，不称上游模型故障恢复。采用建议后没有再次核验，不将修改后的配文说成复验通过。

## 真实请求与费用记录

用户明确授权少量官方真实调用。用户保存的官方配置最初选择 Responses；agent 使用同一份用户密钥切至此前成功录制的 Anthropic Messages 兼容入口，未创建密钥副本，见[配置适配记录](../../evidence/formal-demo-2026-10-18/configuration-adaptation.json)。

入口为 `https://api.deepseek.com/anthropic/v1`，请求和返回模型均为 `deepseek-flash`。**7 次实际模型 HTTP，均为 200，用量完整：输入 9,190、输出 2,649 tokens。** 产品请求为 1 次读图、3 次程序计算、2 次来源初查；程序计算不计作模型 HTTP。另有 9 次余额读取，观察 9.54→9.52 元，0.02 元只是观察差额，不是逐笔计费证明。

18 次 HTTP、余额低于 2 元及观察下降达到 1 元是代理选择的保护值，不是用户金额额度或保证金额封顶。用量未知、输出截断或完成未知会停止；既有预算恢复回归 6/6 通过。旧网关未知请求继续独立保留，不由本批覆盖。

[本批证据](../../evidence/formal-demo-2026-10-18/)保留授权、HTTP journal、产品 API、动作时间、原始章节及用量。没有进入密钥输入界面，归档文件的精确密钥扫描无匹配。生产文件基于 `4b7f90b`，指纹与录制时一致；新增录制工程单独保留，没有修改产品源码、提示词或冻结评测材料。
