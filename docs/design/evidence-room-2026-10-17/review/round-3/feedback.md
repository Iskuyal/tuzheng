# 独立视觉评审

评审对象：图证静态设计稿，版本 `8f7d2739c0796775ff7f7cca7cdf7c789d9d6e3d9dda138bfd9cfc1c521e8cbe`。

已读取固定评审提示及本轮全部 11 张截图。依据仅为截图和事实简报；未读取源码、其他评审或作者说明。

## 1. 总体判断

最强的设计决定：把“判断、比较口径、适用来源、修改建议”排成可阅读的证据链，用米白与深墨绿建立安静的中文阅读环境，并把朱红集中在具体不一致之处，视觉身份与产品任务贴合。

最关键的不足：采用建议后的状态只宣布“配文已更新、旧结果转入历史”，没有同时展示更新后的配文或可见的历史入口，用户在这次关键转换后仍缺少直接复查的抓手。

## 3. 改进建议

1. **P2｜07-states.png，采用建议后状态。** 观察事实：该卡片有“配文已更新，旧结果转入历史”和重新运行按钮，但没有更新后配文，也没有可见的历史查看入口。影响：用户无法在当前状态直接确认究竟写入了什么，或重新找到支撑这次修改的旧判断。具体修改：在状态说明下显示更新后的短配文，保留“尚未重新核验”的标签，并提供“查看上次结果（历史）”；将重新运行保持为主操作。如何复查：补一张采用后的完整窄屏状态，检查普通读者能否仅凭该画面指出当前配文、结果有效性和旧结果入口，无需倒推前一个页面。

2. **P2｜11-error-mobile.png，失败后的操作区。** 观察事实：已保留材料卡片不可见编辑入口，下面只有“重试核验”和模型设置；底部文字却提到“取消或返回”，画面中没有对应返回材料操作。影响：想先改配文或换图再运行的用户，要自行寻找离开失败页的路径。具体修改：增加清楚的“返回材料，继续编辑”文字入口，与重试和设置排成有主次的三个去向；把底部说明直接关联该操作。如何复查：在失败截图上检查“原样重试、检查连接、修改输入”三个意图是否各有明确可指认的入口。

3. **P2｜01-home-desktop.png、04-home-mobile.png，自带图表入口。** 观察事实：入口写“图表＋配文：进入来源核验”，辅助文字只有“只查收录资料”和文件限制；具体哪些资料适用，直到 CPI 样例工作台才更明确。影响：带着其他题材截图来的普通读者，难以在开始前判断这个来源核验入口是否适用于自己的材料。具体修改：在入口附近增加一行当前收录范围摘要或“查看可核验资料范围”入口，说明不适用时会保留待核对；保持图内检查为清楚的备选路径。如何复查：让读者只看开始页，能说出来源核验的资料边界，以及资料不覆盖时可以走的路径。

4. **P3｜06-result-mobile.png，结论至来源之间。** 观察事实：标题、红色提示、核对的主张、解释句和双数字卡连续表达了同比/环比混用，来源卡约在纵向 1000 像素处才开始，建议更靠后。影响：初次阅读有充分解释，但已理解问题的读者要继续越过重复内容才能核查依据；页面目录能缓解跳转成本，不能完全替代紧凑的正文。具体修改：保留顶部结论和核验边界，把主张、解释与数字对照合成一个较紧凑模块，减少重复句和模块间空白，让来源更早出现。如何复查：在 390 宽度下比较调整前后，确保“不一致是什么、正确口径是什么、核验到哪里”为首段可读，同时来源入口明显提前，正文没有丢失必要限定。

5. **P3｜03-result-desktop.png、06-result-mobile.png，来源卡片。** 观察事实：来源文章标题重点是“同比上涨 0.8%”，与本次修改直接相关的“环比上涨 0.2%”位于卡片下方的资料内容小字中。影响：用户扫读来源标题时，仍需再找一次真正支撑修改的数值。具体修改：在资料内容区单独突出“环比上涨 0.2%”，标成支持本次判断的原文片段或资料摘录；保持文章原标题和发布时间完整。如何复查：遮住结论区，只看来源卡，检查读者能否快速指出本次改成 0.2% 的依据；不要把项目摘要误标成原文引述。

## 4. 总体评分

**8.6/10，覆盖当前完整静态设计范围。** 开始、输入、结果和主要异常状态形成了成熟且一致的视觉系统，尤其是来源适用范围、用户补证身份、主动调用模型和采用后须重跑这些边界，大多已用可见文案表达。距离更精细的执行，主要还差任务转换后的复查与返回入口，以及移动结果页进一步压缩重复阅读成本。

置信度：对当前静态构图、信息层级、视觉身份和所示窄屏较高；对未展示的采用后窄屏全页、实际缩放拖动、目录跳转、折叠内容和状态切换无法判断。没有可运行交互或本次在线模型证据，因此评分不代表接口、模型结果、读屏、键盘操作、性能或真实用户验收已经通过，也不要求完成开发才能结束本轮静态设计评审。
