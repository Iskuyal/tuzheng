## 设计决定

用户已确认普通读者优先、首轮完整主流程、米白纸面与深墨绿/朱红的「证据阅读室」方向。

开始页用一个 CPI 示例展示“图上数值相同，比较方式却不同”的具体问题；工作台只围绕图片、配文和主动运行；结果把结论、口径对照、引用和修改建议排成阅读顺序。工具轨迹与运行统计按需展开。窄屏保留结论和依据的顺序，将材料和过程收起，避免把桌面分栏等比压缩。

方向取舍：明亮蓝白应用布局易于沿用，但辨识度较弱；深色调查控制台能常驻高密度证据，但会增加普通读者的初次理解负担。本轮按用户选择采用阅读型构图，保留高频操作的常规控件。

展示标题使用 Noto Serif SC，回退宋体；正文使用 Noto Sans SC，回退微软雅黑；关键数字使用 Georgia。本轮不分发字体文件，不请求在线字体。背景、正文、动作、矛盾、待确认各使用固定语义色。装饰只保留图表框选式标志、细分隔线和证据标注，不增加虚构用户数、评价、合作标志或效果承诺。

## 任务与动作契约

以下是待实现的设计意图，不能视为已运行通过的交互。

| 动作 | 对应现有入口/状态 | 预期结果与恢复 |
| --- | --- | --- |
| 试用来源核验样例 | `/` → `/source-audit?sample=cpi-2025-12` | 只载入自制图片与配文，不调用模型 |
| 从自己的图表开始 | `/` → `/source-audit` 输入态 | 携带选择的图片，填写配文后主动运行；这是待实现的首页图片交接设计 |
| 只有截图，做图内检查 | `/` → `/audit` | 沿用图内路径；无来源时不升级为真实来源核验 |
| 运行来源核验 | `/source-audit` 输入态 → 等待态 | 点击后发送图片和配文；核验期间可取消，材料保留；工具记录在返回后展示 |
| 服务失败/模型未配置 | 同一路由错误态 → 重试或 `/settings` | 清楚说明未生成结论；保留材料；从设置返回后应恢复原输入，这一返回契约待实现 |
| 查看结论、来源、原文 | 同一路由结果态/锚点 → 来源外链 | 首先显示当前结论与限制；引用对应发布者、日期、指标、月份和范围 |
| 采用建议，写入配文 | 结果态 → 输入已变/旧结果失效 | 只改配文，旧结果转为历史；用户再次主动运行，不自动发请求 |
| 提交补充并继续核验 | 缺口径分支 → 恢复核验 | 补充标为用户提供，只确定口径，不充当公开来源；失败后保留回答 |
| 回到材料 | 结果态 → 当前材料锚点/展开区 | 保持同一次任务的图像和配文，不新建会话 |

关键状态已绘制：首次为空、进行中/取消、服务失败/重试、缺口径补证、采用后待重查。缺口径示意适用于配文没有“比上月”或“同比”时；主线配文明确写了“比上月”，不能再让用户确认已有比较方式。

结果示例只说明当前配文与所引资料的关系，不对整张图、图像制作过程或原始数据真实性作背书。用户输入、模型提取、程序计算和适用公开来源应继续分别标识。界面中没有模拟实时工具步骤或本次模型成功率。

结果区顶部为页内目录，点击后滚动到对应章节；过程目录应同时展开对应折叠区，不采用内容互斥的标签页面板。原图预览为新增待实现的查看状态，支持返回、关闭、缩放和拖动；示意图显示 100% 原始像素，原图边缘裁切是可拖动视窗的有意表现。补证使用现有自由文本语义，明确输入标签和示例占位，不预选“同比”；暂不补充时保持待核对，不升级结论。

## 基线与素材

基线来自当前 [PLAN.md](../../../PLAN.md)、[路由](../../../web/router.ts)、来源页与样式的只读检查，以及 2026-10-03 的[历史首页截图](../../evidence/source-entry-ui-2026-10-03/after-final/home-1280.png)。历史截图不是本次运行基线；本轮没有运行生产应用。

保留四个既有路由及模型配置/主动发送/证据边界。首轮没有展开设置页或图内工作台的重设计，没有增加历史路由、账号、开放网络搜索或批量工具。主流程中的历史结果仍是来源页内的状态。

图像使用 [团队自制 CPI SVG](../../../web/public/samples/cpi-2025-12.svg)，嵌入输入和结果源图时保留其自制声明，不把它改成官方原图。来源数据、发布日期和原文 URL 取自项目已保存的 [corpus.json](../../../samples/holdout-v1/corpus.json)，未修改冻结文件、题目或期望。图上未标明比较方式，配文说“比上月上涨 0.8%”；示例来源里同比为 0.8%，环比为 0.2%。这不是本次新发起的实时查询或模型核验。

以下保留仅设计阶段的历史证据；实际 Vue 实施以 2026-10-18 的实施报告为准。

十一张主稿已在 Windows / Microsoft Edge 无头浏览器以各自原始画布渲染。[文字边界检查](render-check.json)记录字体可用性、文字数量与溢出结果，当前为 0 项；该检查只覆盖已声明文字宽度和画布边界，不能替代人工视觉走查。[交付检查](delivery-check.json)记录了 11 组文字/控件色对的计算对比度、本地审阅页 1440/390 宽度的资源与溢出检查、所有稿件链接，以及源图与已评审截图的哈希一致性。选定文字色对均达到 4.5:1，控件边界色对达到 3:1；这不是完整 WCAG 符合性审计。

独立评审使用固定提示与全新上下文，普通设计模式、每轮一名评审，没有分数门槛。当前十一张稿的独立静态总体评分为 **8.6/10**；[第三轮反馈](review/round-3/feedback.md)对应当前文件。[评审与修订记录](review/summary.md)保留历轮版本、原始意见和未采纳/待细化内容；[当前证据清单](review-manifest.json)绑定源图/tokens 指纹和十一张截图 SHA256，交付检查确认当前稿与该清单一致。
