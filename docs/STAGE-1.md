# 阶段一：单图图内审计闭环

**阶段状态：本地功能验收通过；真实云端视觉读取已通过（2026-09-26）；独立 UI 评审已达 9/10（2026-09-26）。** 单图路径已实现并在 Windows 本地运行，上传与样例两条路径都能走完整闭环。

## 用户故事

作为只拿到截图的读者，我想上传图片或选一个样例，看见图表标题与标注数字是否自洽；当模型读错数字时，我能先纠正，再看到可靠的图内计算结果；当证据不够时，系统告诉我还不能判断什么。

## 交付范围

1. Vue 3＋Vue Router＋Vite＋TypeScript 前端，以及 Node.js＋Express＋TypeScript 接口；单个根目录开发脚本同时启动两者。着陆页引导进入审计台；模型设置页允许填写 Responses API 兼容 URL、模型名和 API Key；远程 URL 使用 HTTPS，本机回环 URL 可用 HTTP；密钥只在本机服务端和当前 Windows 用户配置文件中处理。
2. 首页有图片上传和三个自制样例入口：**矛盾**（80、100，标题 40%）、**一致**（80、100，标题 25%）、**无法读清**（一处关键标签模糊）。样例内容和期望结果分开保存。
3. 服务端把图片交给可配置的云端视觉模型，要求其以 `claims[]` 返回结构化图上观察：每项含主张原文、所读到的年份／类别、数值、单位和无法辨认项。阶段一三个样例各返回一个相关主张；模型不返回用户确认状态、计算结果或结论。严格校验模型输出；不从柱子高度臆造无标签的精确数值。
4. 前端先展示模型观察值，让用户确认或更正。未确认时不输出确定的数值结论。用户更正后可重新审计。
5. 确定性检查器只支持一个明确规则：两个已确认数值的增长率 `(新值－旧值) ÷ 旧值`。旧值为 0、单位不一致、时间顺序不清或数字缺失时，返回「需要确认／无法判断」。
6. 结果卡展示图内结论、标题原文、输入数字、公式和计算值。结论状态至少有「图内一致」「图内矛盾」「需要确认」；页面明确说明**这不是对真实原始数据的核实**。
7. 提供加载、超时、模型输出异常、格式不支持和模型配置缺失等状态。未配置 API Key 时，内置样例可用标明「预置示例」的观察值走检查流程，但不能伪装成实时模型结果。

图片来源定位在本阶段以用户裁剪、提取原文与原图并排显示实现；不把自动像素级框选设为通过条件。

## 建议的最小结构

- 前端负责上传、图片预览、观察值确认与结果卡。
- 服务端负责图片大小／类型检查、模型适配与结构化校验。
- 共享领域类型区分**模型观察值、用户确认值、检查结果**，避免把三者混作一个 `data` 对象。
- 增长率检查器是纯 TypeScript 函数，可以独立测试；未来其他检查规则接入同一结果语义。

实现可以调整目录和库选型，但仍须保持一个根目录 `npm install`、`npm run dev` 的 Windows 使用方式。首版数据保存在本地文件或内存中，不引入数据库服务、Docker、WSL 或本地推理环境。

### 「实时视觉模型」的复验步骤（2026-09-26 已按此通过）

更换端点、模型或密钥后重跑这五步；任一项与期望不符，本项仍记为未通过。

1. 打开「模型设置」，填写实际 Responses API 兼容 Base URL、模型名和 API Key，并保存到本机用户配置。
2. 在首页上传 `web/public/samples/conflict.png`，点击「读取整张图片」。
3. 在返回的 `claims[]` 中找到图上可见的对应主张并核对原文与读数：conflict 应包含「年营业收入增长 40%」、2024 年 80 万元和 2025 年 100 万元；用户确认后程序应算出 25% 并判「图内矛盾」，与 `samples/expectations.json` 中 conflict 的期望一致。模型响应本身不得包含确认状态、计算值或结果状态。
4. 对 `consistent.png`（标题 25%，应判「图内一致」）与 `unclear.png`（2025 年标签模糊，应将该主张的新值保留为 null，并在该项 `unreadableItems` 中说明）各重复一次。
5. 把实际读数、耗时和失败情况补进本文件的验收记录。

三个样例以 SVG 保存用于页面展示；上传与视觉读取只接受 PNG、JPG、WebP，因此同内容另存了栅格渲染，供上传路径与演示使用——两者是同一份团队自制内容的两种格式，不引入新的样例含义。（2026-09-26 补充：三主张样例也补了同名 `multi-claims.png`，四张栅格都是 960×640；它的真实模型读取见任务 06 记录，模型返回三条主张、逐点标为「模型读取 · 待确认」，单次 18.1 秒。）

样例图片位于 `web/public/samples/`，样例观察值位于 `shared/samples.ts`，独立预期结果位于 `samples/expectations.json`。仅凭这些截图的判断始终限于图内信息，不核验真实原始数据。
