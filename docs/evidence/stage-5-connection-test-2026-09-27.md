# 模型设置页「测试连接」在线走查（2026-09-27）

在 Edge 390px 视口打开本机模型设置页，使用已保存于当前 Windows 用户配置目录的连接参数点击「测试连接」。服务端向 `deepseek/deepseek-v4.1-flash` 发送一条短文本 Responses JSON Schema 请求，设置页返回「连接成功」，显示耗时 **2,242 毫秒**。测试前后的公开设置字段（Base URL、模型、`hasApiKey: true`）一致；没有通过测试接口保存密钥或表单改动，页面没有横向溢出。

测试只验证当前服务地址、密钥、模型对 Responses 结构化文本请求可用；**没有在这次测试中发送图片**，也不代表视觉识别准确率或真实来源核验通过。图片读取及两图结果另见[阶段三在线复验](stage-3-live-vision-2026-09-27.md)。API 替身测试与三个视口的浏览器自动化覆盖成功、鉴权错误、无密钥及未保存表单值的行为；替身通过不计作在线调用。
