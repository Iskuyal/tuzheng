## 实际交付

- `createModelSettingsStore` 统一选择完整 `file/env` 配置源。省略／留空／显式 `file` 保持文件行为，忽略所有模型环境字段；显式 `env` 对协议、地址、模型、密钥取一次快照，不读取文件或逐字段回退。非法来源选择明确启动失败。
- 环境缺项、空白、非法协议、超长字段或不安全地址明确失败。两种来源共用 HTTPS／回环 HTTP 根地址校验；错误只含变量名和规则，不回显输入值或原始校验信息。
- 设置接口返回 `configuration.source/readOnly`；环境模式下页面显示来源、协议／地址／模型、密钥配置状态并锁定编辑，密码框始终为空。服务端拒绝保存／清除与连接测试的表单覆盖；环境连接测试只接受 `{}`，手动点击后才调用当前完整配置。
- 读图（含对照图）、连接测试、来源初查和命令行评测统一选择配置源；恢复调查复用初查驱动器和内存会话，环境变更需重启。
- 来源调查日志改为固定提示；评测失败记录只保留分类和 HTTP 状态，余额预检同样避免记录上游原始异常／请求头中的密钥。
- 同步项目约定、产品计划、领域词汇、阶段规格、README、部署说明、环境模板、结构说明、官网／评估记录的后续补充、访问检查与赛事 HTML/PDF。旧开发 PDF和历史在线结果保留原轮次。赛事 PDF仍为 16 页，配置补充注明来自本地工作区。

配置方法见[模型配置说明](../MODEL-CONFIG.md)；任务见[01 配置源](../../.scratch/model-config-env/issues/01-config-sources.md)。

## 消费入口核对

| 入口 | 配置获取与本轮证据 |
| --- | --- |
| `GET/PUT /api/settings` | 同一配置源；文件保存、迁移、保留／清除密钥和损坏恢复回归；env GET 仅公开非密钥字段，PUT 为 409 |
| `/api/settings/test-connection` | file 保留未保存表单及密钥行为；env 用完整快照，拒绝覆盖；两个协议均有替身测试 |
| `/api/audit/image` | 主图／对照图共用；env 两协议传给工厂的四项与快照一致；缺项阻止工厂调用，异常不泄露密钥 |
| `/api/source-audit/investigate` | 两协议工厂收到相同完整配置；缺项阻止调用，错误响应／日志不含密钥 |
| `/api/source-audit/resume` | 两协议替身走完检索／追问／汇总 → 同记录补证 → 来源一致；只创建一次工厂，复用原驱动器，不读文件、不回传密钥 |
| `scripts/evaluate-source-audit.ts` | 加载根目录 `.env` 并使用统一入口；真实 CLI 在 file/env 假配置下因冻结协议／模型不匹配退出（码 1），在任何模型或余额请求前停止；失败替身的日志和可落盘记录不含上游密钥 |
| SDK／请求器 | 从完整 `ProviderConfig` 显式传入地址、模型、密钥；本轮静态核对及既有请求形状替身测试，未发出真实模型请求 |
