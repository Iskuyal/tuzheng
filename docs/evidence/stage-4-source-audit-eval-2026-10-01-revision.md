# 阶段四 06「版本修订与版本替代」整组真实模型评测（2026-10-01）

在用户批准把固定资料库扩到「社会消费品零售总额」之后，按整组口径跑了一轮真实模型配对评测：**22 题 ×2 臂 ×3 次 ＋ 1 道补证题的恢复段**（计划 138 次请求），验证新增的「版本修订／版本替代」在真实模型下成立，并同时复核既有 20 题没有被这次资料库扩张扰动。

```powershell
npm run eval:source-audit -- --record=docs/evidence/stage-4-source-audit-eval-2026-10-01-revision.json
```

模型与冻结配置：`anthropic` / `deepseek-flash` / `https://api.deepseek.com/anthropic/v1`；题集与期望冻结于 **2026-10-01**（22 题，其中 q21／q22 为本轮新增的版本修订题）；资料库五条材料的指纹全部与 `frozen.libraryFingerprints` 一致；预算常量（每轮 3 次／总计 6 次／4 轮／150 秒／最多 1 次追问）与冻结值一致。开跑前免费余额预检：**15.47 元**（下限 1.00 元）。

## 本轮未通过／漂移（如实保留，不删题）

- **q06（范围错配）1/3**：两次运行模型没给出可匹配的配文主张（`no-matching-claim`，其中一次整轮无结论），与本轮改动无关，属既有模型漂移。
- **q16（配文超三条主张）2/3**：一次运行整轮无结论。
- **q18（先检索后追问 → 补证恢复）2/5**：一次运行没有提出追问（追问率漂移是已记录的既有局限），恢复段因此无法运行；另一次补证后没有把用户补充套用到主张。补证前状态与恢复段其余运行按期望通过。
- **q20（两处改动并存）2/3**：一次运行的建议数值不符合期望（`suggestion-missing-number`／`forbidden-number`），属建议生成侧既有波动。
- 整体：有检索臂 89.7% 低于上一轮（阶段四 05 的 93.5%），但**题集从 20 题增到 22 题、分母不同**，且上述漂移与新增能力无因果关系；两轮分开计数，不合并、不外推。

## 不能外推的部分

- 题型仍是团队自制开发题、没有预留题；只验证了 `deepseek-flash` + Anthropic Messages 协议（Responses 协议工具循环仍只有替身测试）。
- 「同口径冲突 → 来源存在分歧」**没有实现**：本轮在国家统计局公开发布里没有找到任何可核对的分歧来源对，故不做能力声明、也不在题集里造题。
- 国家数据月度库（`data.stats.gov.cn`）本机被 WAF 拦（403），新基期下 2025 年各月的月份级新旧值没有核到，故未纳入任何结论。
- 修订关系只覆盖「有官方修订声明」的发布；没有声明、只有数值差异的材料一律不按修订处理。
