# 阶段三真实模型读取复验（2026-09-27）

本次使用本机设置页保存的密钥，通过仅监听 `127.0.0.1` 的服务端上传团队自制 PNG；模型为 `deepseek/deepseek-v4.1-flash`，请求走真实 Responses API。记录仅包含通过结构校验后的观察、耗时和用量，不包含密钥或模型原始全文。

初次设置把 Base URL 填到了 `/chat/completions`，首张图片返回 `VISION_REQUEST_FAILED`（HTTP 502）。按 [Command Code 官方 Provider API 文档](https://commandcode.ai/docs/provider)改为 API 根路径 `https://api.commandcode.ai/provider/v1`，由应用调用 `/responses` 后重试成功。设置页读取接口只显示 `hasApiKey: true`，不回传密钥。

四次请求均返回 HTTP 200、有效 `claims[]` 结构，模型未返回确认状态或计算结论。三主张预置示例里“利润新值 70”是刻意安排的**预置待更正观察**；本次真实模型从图上读到的是 `100`，两者不能混作同一次读取结果。

另用 Edge 完整走页面上传路径：上传 `cross-a-revenue.png`，页面显示“模型读取”与读取轨迹；确认当前图后上传 `cross-b-conflict.png` 为对照图、确认对照图读数，四要素显示一致，程序给出“数值冲突：当前图 25%、对照图 50%，相差 25 个百分点”，并并排显示两侧原图摘录。1280px 视口无横向溢出。
