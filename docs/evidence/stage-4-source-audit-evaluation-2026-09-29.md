## 一、这条路径要证明什么

不是证明系统抓到了现实真相，而是证明**模型在有／无公开来源两种条件下的判断差异是可复核、可量化、有边界的**：

1. 题集与期望分开冻结，期望由人先写，不由模型生成或按运行结果回填；
2. 两臂除检索工具可用性外配置一致，无检索臂不得静默回落检索结果；
3. 事实正确性、证据可追溯性、不适用来源识别**分别**报告；
4. 未达标就如实记录并缩小声明，不删除失败题，也不只报通过的那部分。

## 五、三个维度分别报告

**事实正确性。** 有检索 91.3%（94/103），无检索 39.6%（36/91），配对差 51.7 个百分点。第 C 轮逐题配对：仅检索臂正确 8 题，仅无检索臂正确 0 题，两臂均未通过 0 题，两臂相同 4 题。允许无检索答对——这 4 题里有 3 题（第 7、8、12 题）的正确答案本来就是「来源待核对」，无检索臂无法给确定结论，因此**免费**答对；第 11 题两臂都答对，但无检索臂是因为它把配文主张判成待核对，正好与期望一致。检索臂的增益只体现在资料库确实覆盖的那几题上。

**证据可追溯性。** 有检索臂三轮共接受引用 228 条：数值依据 91、术语解释 102、仅作背景 35。被拒绝的引用共 16 条，全部是「引用了本次命中内、但与主张口径不符的材料」，理由逐条可见（如「所引资料与主张口径不一致（月份）／（范围），不作为数值依据」）。应有正确材料才能给出确定结论的 7 道题里，有 3 次运行没拿到应引用的材料（A 轮 0 次、B 轮 2 次、C 轮 1 次）。**引用可追溯性的提高没有被当成准确率提高**：引用条数在无检索臂恒为 0，正是设计使然。

**不适用来源识别。** 干扰来源 `stats-cpi-2026-08`（同比同为 0.8%）与术语页 `stats-term-yoy-mom` 在绝大多数运行里被正确排除并给出原因；按同值干扰项设计的第 5、9、10 题，三轮共 26 次有效运行里有 24 次在被接受的引用里包含正确月份的材料（例外的 2 次是修复前正确引用被按查询口径拒绝的那两次，见第八节）。三轮合计「无适用来源案例却给出确定来源结论」为 0 次——包括无检索臂 91 次有效运行。

## 七、模型主动请求确认（真实路径）

`request_clarification` 在无检索臂被真实调用 **5 次**（第 A 轮 3 次：q02、q04、q11；第 C 轮 2 次：q08、q12），有检索臂 0 次。第 C 轮记录里保留了原文，例如：

- q08：问「配文『12 月物价上涨 0.8%』中所说的 0.8%，指的是同比（与上年同月相比）还是环比（与上月相比）？」用途写明「确定后才能判断该主张与所引发布是否一致」。
- q12：问「你希望我按哪个口径来核查这条主张：是核查图片与配文的一致性，还是核查『环比』这个术语本身是否等于与上年同期比？」用途写明本次无检索工具、术语口径只能列为未解决项。

也就是说，「至少一条真实路径展示请求确认或停止」在无检索条件下真实成立；**有检索时模型从未主动追问**，这条仍是任务 04 要解决的问题。停止路径同样真实：有检索臂 5 次、无检索臂 17 次上游请求失败，页面与服务端都如实降级、不写回任何结论。

## 八、本轮由固定题集暴露并修复的两处程序口径问题

1. **结论组合按检索查询的口径判适用性**（离线单测发现，修复后第 A—C 轮都含此修复）。`concludeClaimSource` 原先只看命中资料在「检索查询」下是否口径适配；同一次调查会按多个口径检索，命中里同一份资料的适用性是按某次查询算的，不代表它对某条主张适用。现改为按**这条主张自己**的指标／月份／范围判定。
2. **引用校验同样按查询口径拒绝**（第 B 轮真实运行发现：q05 的模型正确引用了 2026-08 发布，被程序以「口径不一致」拒绝，结论退回待核对）。现改为：结构校验只判断「是否在本次命中内、角色是否与资料类型相符」，口径是否适配按**主张**判定；命中内但与任何主张口径都不符的引用，才进入「被拒绝的引用」并给出月份／范围等具体原因。第 C 轮该题 3/3 通过。

修复带来的方向是单向的：只会把「本可以给出确定结论却被拒」的少判变成正确结论，不会新增越界结论——门槛里的「虚构引用为零」「无适用来源不下确定结论」在第 C 轮仍为 0。第 A、B 轮的 90.9%／91.7% 与第 C 轮的 91.2% 不能直接相加当作同一个程序的成绩；上表的「合计 91.3%」只是把三轮放在一起看的观察值。

## 九、不能外推、尚未验证的部分

- 12 道题全部是开发题，没有预留题；样本量与题量都不足以给出通用准确率，只能说明**这套题集上**的结果。
- 只验证了 `deepseek-flash` + Anthropic Messages 协议；Responses 协议的工具循环仍只有替身测试。
- 无检索臂的上游失败率明显高于有检索臂（17/108 对 5/108），本轮不足以判断原因。
- 「配文只写月份、模型不去图上取年份」导致 4 次运行退回待核对；这是模型侧的填写缺口，程序降级方向正确，但意味着**配文不写年份时覆盖率会下降**，修复属于任务 03／04 的主张拆解范围。
- 模型把检索到的官方原句当成一条配文主张（q04 一次）说明输出仍需更严的主张归属校验，本轮只记录未修。
- 术语类主张（q12）目前只能到「来源待核对」：结论词汇只表达「与数据发布是否一致」，不能表达「配文对术语的解释与术语页矛盾」。这是能力边界，不是本次达标项。
