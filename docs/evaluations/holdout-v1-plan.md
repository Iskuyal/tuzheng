## 预留题成立条件

12题覆盖六类边界，并包含两条补证路径、双主张覆盖和旧图/新配文版本交叉。新题未用于当前调参，独立期望来自原页核对和算式，生成过程与生产判定函数分开。仍沿用当前指标家族及已有资料，不宣称题目作者盲审或跨领域泛化。负责人在首轮真实运行前逐题抽查，尤其核对signed数值、图文口径和版本链；抽查状态单独写在签字记录中，本次不冒充已完成。

如果看到本批真实结果后调整模型、提示词、检索规则、结论或改写保护，本批退为开发题。保留原冻结包/原始响应/原判，不覆写历史；补充新预留集才可声称未见题验收。复核的有效改写措辞另记人工语义判，不以覆写自动判的方式增分。

## 输入与公平性

| 臂 | 输入 | 执行 | 可引用来源 |
| --- | --- | --- | --- |
| A | PNG、配文、A提示词 | 一次直接JSON；必要时一次用户补证 | 无已提供的外部资料，事实猜测与证据支持分开 |
| B | 同上，加完整corpus.json | 一次直接JSON；必要时一次用户补证 | 全部五份资料的合法sourceId，不要求搜索 |
| C | PNG、配文、当前提示词及工具声明 | 当前runSourceInvestigation，必要时原会话恢复 | 实际命中+显式程序版本复查，仍须逐主张适配 |

B/C 使用的资料来自同一份原文，逐字一致。B 传入完整 document 对象，包括 measures、逐行月份、术语页和 revision，不能只传检索摘要；C 不预先获得全集，也不为题目预选正确的搜索。B 的引用只按可见资料、指标/月份/范围/比较方式及独立期望验证，不能仅因没有 tool trace 就判错。C 必须记录真实工具调用，不能用固定动画或替身作为在线证据。生产审计器不会更正 A/B 的原始直接输出；C 的模型提议、拒绝记录和程序产物均保存在 raw/trace。

三臂最终转换为相同字段：逐字主张、图/配文出处、类型、指标/月份/范围/比较方式、带符号数值、推断方向、判断状态、对照值、数值依据sourceIds、版本替代起点、追问、停止理由和逐处改写。适配器负责转换 C 的生产报告格式，转换后的确定性结论不能记作模型原始判断。A 可能答对事实但缺少证据；完整来源核验仍须有证据支持，因此另行报告 factualPaths，避免只用完整来源路径分数评价 A 的事实判断能力。

图中抄录、期望、题类、算式、来源核对笔记和负责人意见均不得进入请求。仅当初查提出正确字段、正确配文目标的追问，才把questions.json预先写定的回答放入恢复；缺追问、追错主张或初查失败则恢复记blocked。补证只改变目标配文，不能修复图上原始缺失口径。B/A的DirectSession需保持原始对话/响应，after输入中的prior用于恢复，不能传评分结果。

## 指标与分母

配对单位为`questionId × repeat`；每臂观察单位为`questionId × repeat × arm`完整路径。主张身份为逐字原文（忽略空白/句尾标点）+fromImage；精确拆分失败按覆盖缺失计，不能按首条匹配忽略遗漏/重复/额外主张。

| 指标 | 分子/分母与处理 |
| --- | --- |
| 主张覆盖 | 唯一匹配主张数/期望原子主张数；漏项、重复不计；额外主张单独失败 |
| 数值 | 原主张值及该题对照值均正确/具有数值检查的期望主张；有符号，容差1e-9；缺失输出计错 |
| 口径 | 指标、月份、范围、同比/环比、类型全部正确/所有期望主张；CPI常用名称归一，不补缺字段 |
| 方向 | 正确up/down/有方向期望的推断；null不进入方向分母，带符号直接主张在数值指标核对 |
| 事实判断 | 期望状态正确/所有期望主张；A的记忆判断与B/C用同一独立状态核对 |
| 有效引用精度 | 实际提供且逐主张口径适用的数值引用/全部输出数值引用；不引用时无精度分母，不能写100% |
| 引用覆盖 | 有有效引用的明确支持/矛盾主张/期望明确支持/矛盾主张；空引用会降低覆盖 |
| 有依据主张 | 状态、数值、口径、方向、引用及必要版本链全对/所有期望主张 |
| 恰当停止 | 正确追问或无适用来源/推断依据不足时安全停止/需停止或追问的计划阶段；不该问却问仍使完整路径失败 |
| 错误改写 | 无允许改写依据或重复的输出改写数/输出改写数；同时报告改写覆盖，空输出不能靠0错误通过 |
| 改写覆盖 | 给出唯一允许修改建议/期望配文主张数；按冻结字句主评，空白/标点/数字尾零归一，其他有效措辞可另附人工判 |
| 阶段成功 | 全项通过且运行成功的阶段/全部计划阶段；保留failed/blocked/planned |
| 完整路径成功 | 初查和必要恢复均运行并全项通过的路径/全部计划路径；不能只算恢复阶段 |
| 事实路径成功 | 初查和必要恢复均事实/数值/口径/方向/覆盖正确的路径/全部计划路径，单列A的事实能力 |
| 耗时 | 请求、阶段、完整机器路径原始毫秒；报告中位数和样本数，失败计入已尝试阶段；blocked无执行时间为null；不包含人工等待 |
| tokens | 每实际HTTP输入/输出usage之和；missingRequests列出未知数，未知不填0、不臆测；known之和只是已知部分 |
| 请求数 | HTTP传输层实际尝试次数，失败和兼容重试都计；工具调用另有trace，不能当HTTP次数 |

完整报告要同时列全部计划路径、已尝试阶段、失败、阻塞和未执行数量。12题×3重复×3臂=108计划路径；两道恢复题使阶段总数126。逐题/重复列C−A、C−B的gain/no-gain/regression，保留两臂都失败和对照臂正确而工具臂错误的记录，不做只选成功题的汇总。小样本为描述性结果，不作统计显著性或普遍增益结论；C−B比较的是整个工作流，不可仅归因于检索。

## 离线入口

```powershell
npm run eval:holdout -- --verify
npm run eval:holdout -- --offline --output .cache/holdout/offline-新轮次.json
npm run eval:holdout -- --report .cache/holdout/offline-新轮次.json
```

`--verify`核对锁，不刷新。冻结包按字节封存并用包内.gitattributes禁止自动换行转换；运行源码及依赖锁指纹先统一LF换行，跨Windows检出仍能验收。`--offline`执行A/B直接响应替身及真实C编排+脚本化driver，含故意503、遗漏、错误改写和退化；默认重复1次，36路径/42阶段。JSON每个阶段落盘并保留raw/trace/usage未知；指定已存在的文件会失败，避免覆写历史。`--report`按当前冻结期望重算，不执行请求；缺行/重复行被拒，不能缩小失败分母。CI会运行冻结核验和单元行为验证，不配置模型密钥，不做真实运行。
