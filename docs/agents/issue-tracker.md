# 任务跟踪：仓库内 Markdown

本仓库的规格和任务以 Markdown 文件保存在 `.scratch/`。

## 约定

- 每个功能单独使用一个目录：`.scratch/<功能名>/`。
- 规格文件为 `.scratch/<功能名>/spec.md`。
- 每个实现任务单独保存为 `.scratch/<功能名>/issues/<编号>-<简短名称>.md`，从 `01` 开始，按依赖顺序编号。
- 每个任务文件开头附近使用 `Status:` 记录分诊状态。
- 后续讨论追加在文件末尾的 `## Comments` 标题下。
- 技能要求发布规格或任务时，在对应功能目录下创建文件。

## Wayfinding 任务

- 路线图文件为 `.scratch/<努力项>/map.md`。
- 子任务保存在 `.scratch/<努力项>/issues/<编号>-<简短名称>.md`。
- `Blocked by:` 列出阻塞该任务的编号；只有所有阻塞项都已解决，任务才可开始。
