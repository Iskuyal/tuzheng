# 证据阅读室 UI 实施与本地验证

> 后续用户指出设置页未换主题，已另开全站补齐任务；最新覆盖范围及本轮测试见[全站 UI 补齐与验证](2026-10-18-evidence-room-full-ui.md)。下文保留第一项任务当时的范围、版本和结果，不代表全站交付。

2026-10-18。用户已确认按 2026-10-17 的设计实施。范围是「开始 → 图片与配文输入 → 来源结果与证据 → 补证或采用后重查」一条端到端路径；图内审计和设置功能保留，仅共用导航与返回入口。

## 实际交付

- 首页、来源输入与结果采用米白纸面、深墨绿、朱红的阅读排版，布局覆盖桌面与 320/390 窄屏。首页明确区分来源样例、自带图文和图内检查；原有 11 个自制图内样例保留在展开区。
- 首页图片通过按目的地区分的内存交接进入来源页，不自动发模型请求。来源页缓存只在当前应用内存生效；从设置返回保留图片、配文和已有记录，刷新或关闭页面不作持久恢复承诺。再次从首页明确选择 CPI 样例会替换旧材料。
- 结果继续消费现有真实端点的主张、结论、引用、建议和工具记录，未把设计图中的 CPI 数字写成通用核验结论。摘要先说判断，主张卡展示已有有效数值依据；完整来源、未采用材料、拒绝引用、停止原因和历史记录仍可复查。
- 原图预览使用原生对话框，支持适合屏幕、原始像素、缩放、滚动、鼠标拖动、方向键、Escape 关闭及焦点返回。设置返回目标限制为站内来源页。
- 错误、补证、取消、暂不补充及采用后失效沿用现有状态隔离。错误与失效在页首及主动作附近有对应说明，采用后显示当前配文与历史入口，仍需主动重查。
- 附注的中文引文若既不出现在原配文、也不出现在建议配文，会进入“未匹配到当前配文的附注”，不计为当前配文的未核验项；原响应记录保留在详情中。这里只做字面引文对应检查，不等于语义或来源核验。

源文件主要位于 `web/pages/LandingPage.vue`、`web/pages/SourceAuditPage.vue`、`web/evidence-room.css`、`web/components/OriginalImageViewer.vue`，以及共享导航、数值卡、页面缓存和图片交接处。没有改服务端、共享核验规则、资料库或冻结题集，没有新增依赖或变更 npm/TS/CI 入口。

## 回归与失败记录

1. 改版前新增四条用例均失败，覆盖首页图片交接、设置返回、原图预览和取消新选图。最后一条复现了预览还在、待核验文件却被清空的问题；已改为取消时保留原材料。
2. 首次 66 条集成运行有 56 通过、9 失败、1 跳过：三个尺寸各有旧标题/设置返回 URL 预期与新界面不符，以及负 tabindex 使工具详情 summary 不能自然 Tab 到达的问题。前两项按已授权 UI 契约更新断言，后一项修复真实键盘路径；没有修改模型评测标准或冻结期望。
3. 页面缓存带来再次选择 CPI 样例仍保留旧配文的问题，先重现为失败，再通过明确的首页样例选择意图修复；设置返回和浏览器返回不据此自动替换输入。
4. 既有 UI 替身响应附带“物价压力缓解”未核验说明，但当前测试配文只有“比上月上涨 0.8%”。这是替身内容对应问题，不代表真实模型已复现。新增失败回归后，原记录保留、未对齐项单独归属，默认不再把它当成当前配文说明；用例同时检查原记录可展开。
