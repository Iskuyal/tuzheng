# 2026-10-29：正式赛道与预指导表单的材料要求

本次实际读取[赛道详情](https://www.boxuegu.com/matchTrack/detail/?id=10037)与[金山预指导表单](https://f.kdocs.cn/ksform/w/write/YEH4ZvlT#routePromt)。前者使用实时页面抓取；后者远程抓取失败后，改用本机 Edge 只读读取动态正文。表单显示登录后才能填写，未登录、填表、上传或点击提交。[核对记录](../evidence/submission-prep-2026-10-29/requirements.json)保存要求和范围。

## 两个入口分别做什么

| 入口 | 页面确认的用途与时间 | 操作 |
| --- | --- | --- |
| 赛道详情 | 省赛正式作品截止为2026-11-18，具体提交入口在缴费后个人中心的所报赛项中 | 届时按正式入口要求另行提交并保存回执；未推定具体截止时分 |
| 金山表单 | 省赛作品预指导，页面显示截止2026-10-31 15:00:00 | 每队仅一次，由队长或指定一名队员提交；预指导后仍须重新提交省赛正式作品 |

## 正式赛道要求

代码须托管于 GitHub/Gitee 并公开或向评审开放，保留完整 Git 历史，提供 README、环境说明及依赖。视频须为5–8分钟、至少1080p的MP4，包含普通话讲解、项目介绍、核心功能与AI技术亮点。技术报告须为不超过30页的PDF，覆盖需求、架构、AI方案、实现、测试部署、总结及创新。公网应用演示为可选，不填写虚构部署地址。密钥不得放入公开仓库，正式提交后的变更按组委会要求处理。

## 金山表单逐项要求

| 项 | 页面内容 | 准备方式 |
| --- | --- | --- |
| 1 | 提交作品的成员uid | 指定提交人核对自己的实际赛事UID，不猜数字 |
| 2 | 团队名称 | 岭南凤翔团队 |
| 3 | 学校 | 岭南职业技术学院（清远校区） |
| 4 | 联系人手机号 | 由提交人填写已核对的真实号码，不进入公开仓库 |
| 5 | 完整作品文件链接 | 上传完整材料至百度、夸克、阿里云盘等主流网盘，再填写有效链接；页面建议长期有效并附提取码 |
| 6 | 作品介绍文档 | 最多1个文件，单个100MB以内；内容须覆盖下方七项 |
| 7 | 演示视频地址 | B站、抖音等可公开观看的视频平台播放页，不能用百度网盘视频链接 |

第6项须说明：项目详情与使用方式、亮点、AI测试技术落地情况、关键技术、项目图片、此前发表或获奖情况，以及基于其他项目时的优化部分。已据此制作独立[作品介绍PDF](../submission/tuzheng-project-introduction.pdf)，详细技术PDF另放完整作品包。

两个页面均未显示统一ZIP命名格式，也未给出完整网盘作品包的大小上限。100MB限制对应第6项单个附件，不能扩展为第5项完整作品包限制。打包结构和文件名由本项目整理，属于提交建议，不冒称官方强制要求。原生DOM没有提供完整必填规则，本轮按七项全部准备，实际校验以登录后的表单为准。

具体文件选择和操作顺序见[提交指导](../submission/pre-guidance-submit-guide.md)。
