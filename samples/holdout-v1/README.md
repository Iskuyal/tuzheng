# 独立预留题冻结包 v1

这12道题于2026-10-02新建，未用于现有22题的模型/提示词/检索规则调参。题面、12组SVG/PNG、图片抽查转录、独立期望、资料全集、提示词、工具声明、核对笔记、协议与运行代码均以SHA-256封存。期望的数字来自独立核对的国家统计局正文/表格及算式，未用生产判定器生成。

本批仍复用当前CPI/社零指标与固定资料家族，证明的是未见题面组合的泛化，不证明未知领域/新网站泛化。题面/图片与开发集不同；精确重复核查不等于证明不存在近似语义重合。著题者与评分器作者为同一执行者，来源独立不等于人员盲审；负责人抽查仍待完成。

## 三臂

- A-direct：PNG+原配文，直接JSON响应，无工具/外部资料。事实判断、证据支持分别计分，记忆数字答对不被事实评分自动判错。
- B-full-context：相同PNG/配文+corpus.json五份完整资料，直接JSON响应，无搜索/计算工具。全集内合法来源均可直接引用；没有搜索动作不扣分。
- C-tools：相同PNG/配文，当前生产工具循环，固定为同一资料库；资料只能来自实际工具结果与显式程序版本复查。模型提议与程序最终结果均保留。

A/B的提示词保持同一结构合同，只按资料可见性改变证据说明；C冻结当前生产提示词和工具声明，通过适配器投影到同一最终评分结构。C包括受限工具、确定性判定/改写保护与版本复查，C−B衡量整套工作流，不应单独归因于“搜索”或“Agent”。A/B不会被评分器纠正后再当作模型答对。

## 封存与使用

`manifest.json`是完整文件及运行代码锁。题面、图片、期望、提示词、资料等按原始字节锁定；包内.gitattributes禁止Git自动转换换行。源码/依赖锁的运行指纹采用UTF-8内容并统一LF换行，避免Windows检出导致误报。`npm run eval:holdout -- --verify`只读验证，不刷新哈希。修改任何被冻结内容都会失败；正式封存后的必要修复需保留v1及其记录，建立v2并重新声明冻结边界。manifest自身的SHA-256写入每份运行记录，并在交付记录中另存根哈希。哈希证明完整性，不证明人员独立、未接触题目或答案质量。

未来如果任何模型输出被用于修改模型配置、提示词、检索、判定或改写保护，该批题立即退为开发题；不能继续称为独立预留测试集。修改期望必须留下原判与说明，不能为提高分数覆写本包。负责人抽查不要提交给模型，修复实现后应另建未见题再验收。

实际运行、分母、失败处理和收费运行前置项见[三臂运行计划](../../docs/evaluations/holdout-v1-plan.md)。本包不含真实模型成绩。离线替身仅验收评测机制，不检验模型或OCR能力。
