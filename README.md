# 图证

图证帮助只有图表截图的读者检查标题与图中标注是否自洽。阶段一的单主张审计路径仍可选择原有样例或上传图片，确认/更正观察值后由程序计算增长率；阶段二任务 01、02 已本地验收，三主张预置示例支持逐条查看、修改、确认和重算。会话记录、清除和窄屏浏览器自动化仍待后续任务。

**阶段一状态：本地可验证功能验收已通过；独立 UI 评审仍在迭代；真实云端模型调用尚未验证。** 本机设置页尚未保存真实 API Key，因此样例使用明确标为“预置示例”的观察值；系统不会把预置结果说成实时 AI 输出。

最近一次已完成的独立 UI 评审为 8.4/10；本轮已按反馈调整窄屏步骤栏、首页上传提示和证据标签，并通过本地走查，但本轮复评没有返回评分。先前设定的 9/10 界面门槛尚未通过，复评列为待办。

## Windows 快速开始

需要 Node.js 22.12 或更高的 22.x，或 Node.js 24.x；阶段验收使用 Node 24.16、npm 11.17。

```powershell
npm install
npm run dev
```

打开 <http://127.0.0.1:5173>。根目录脚本会同时启动 Vue/Vite 页面和 Express API；API 默认使用 `127.0.0.1:3001`。

要启用新图片的视觉读取，打开页面右上角的「模型设置」，填写 Responses API 兼容 Base URL、模型名和 API Key。当前预填的 `https://api.openai.com/v1` 与 `gpt-4.1-mini` 是 OpenAI 候选示例，可替换，尚未做实时调用验证。远程服务地址必须使用 HTTPS；本机回环服务可用 HTTP。设置只经本机 Node 服务端保存到 `%LOCALAPPDATA%\TuZheng\settings.json`；读取接口只返回 URL、模型名和密钥是否已配置，不回传密钥。`.env.example` 仅保留可选 API 端口。设置文件使用当前 Windows 账户的本机文件权限；同一账户下运行的其他程序也有权读取。上传的新图会发送到设置页中指定的服务；预置样例不调用云端模型。

### 在 WebStorm 里构建与运行

可以不碰终端，直接在 IDE 里完成：打开根目录 `package.json`，点 `dependencies` 上方的“Run 'npm install'”提示装依赖，再点 `scripts` 里各条命令左侧的 ▶ 运行。`dev` 会同时起前后端，`build` 做类型检查加打包，`test` 跑行为测试。全部脚本也能在 View → Tool Windows → npm 里看到。

`tsconfig.json` 是一份“解决方案”配置：它自己不检查任何文件，只指向 `tsconfig.web.json`（`web/` 与 `shared/`，带 DOM 与 vite/client 类型）和 `tsconfig.server.json`（`server/`、`shared/`、`tests/`，带 Node 类型）。这是刻意的——一旦让它认领源文件，IDE 就会用缺少这些类型的设置去检查代码，报出并不存在的错误。命令行与 IDE 的检查入口都保持为 `npm run typecheck` 与 `npm run build`。

| 四个自制样例、图片放大/手动框选与 PNG/JPG/WebP 上传 | 已实现并本地验证 | 原有三个样例保持确认/计算流程；新增多主张样例可逐条展开原文观察与证据；上传大小上限 5 MB |
| 单图 `claims[]` 观察结构与多主张预置样例 | 已实现并本地验证 | 模型/API 契约只返回原始观察；第四个样例明确标为预置示例。每条主张可独立编辑并确定性重算；会话记录待阶段二任务 03 |
| 服务端 Responses 视觉适配器、结构化输出和观察值校验 | 已实现；实时调用未验证 | 适配器请求契约、结构校验与无密钥错误有自动化测试；本机设置尚未配置真实 API Key |
| 模型设置页 | 已实现并本地验证 | 自定义 Responses Base URL、模型名与密钥保存在本机用户配置；服务端读取接口不返回密钥 |
| 用户确认/更正单条数字，程序计算增长率 | 已实现并本地验证 | 阶段一单主张路径的原文摘录只读，数字可确认/更正且可回到原图；当前 39 条自动化行为测试覆盖计算边界、结果分级、缺证据、样例/API 结构和设置安全 |
| 图内一致、图内矛盾、需要确认及证据/公式说明 | 已实现并本地验证 | 三例浏览器走查与自动化测试 |
| 原始数据或真实来源核验 | 未实现 | 仅凭截图不会声称核实了真实数据 |

计算使用 `(较新值 - 较早值) / 较早值 × 100`。计算值四舍五入到两位小数后，与标题中的百分比精确相等才判为“图内一致”；数值、单位、时间顺序、图中文字依据或标题主张不完整时降级为“需要确认”。

上传文件只在请求期间保存在服务端内存，不写入项目目录。模型读取失败、超时、图片格式不支持或密钥未配置时，页面显示对应说明。模型设置文件位于当前 Windows 用户的 LocalAppData；同一 Windows 账户下的进程也可读取该文件。

## 产品边界

当前只检查一张截图中明确可见的标题、两个时间点、数字与单位。图内一致或矛盾不代表原始数据真实或虚假。跨图比较、坐标轴风险、来源核验、RAG、MCP、登录协作和公网部署留待后续阶段。
