# 图证（暂定名）

面向只有图表截图的普通读者：检查图表文字、数值和呈现方式是否自洽，并明确哪些判断还缺原始来源。项目处于**规划完成、阶段一待开发**状态，目前没有可运行的应用。

## 阅读顺序

1. [产品蓝图](PLAN.md)：目标用户、证据边界、产品体验与技术骨架。
2. [分阶段路线图](docs/PHASES.md)：每一阶段的交付、依赖和验收。
3. [阶段一任务](docs/STAGE-1.md)：第一条可运行的单图审计闭环。
4. [阶段一新会话提示词](docs/STAGE-1-PROMPT.md)：复制后在新会话中启动开发。
5. [比赛原始文档](AI-WEB网页开发挑战赛文档.md)：赛题与评分依据。

## 已确定的边界

- 第一用户是只有截图、没有数据文件的普通读者；内容编辑是第二用户。
- 截图只能支持图内自洽检查；提供可核查来源后才进入来源核验。
- 演示材料由团队自制或选择允许公开使用的资料，不依赖学校授权、数据或接口。
- 技术路线为 Vue 3＋Vite＋TypeScript、Node.js 服务端及云模型 API；开发与演示可在 Windows 上运行，不依赖容器、WSL 或本地 GPU。

仓库中的计划描述**待实现目标**，不表示功能已经交付。阶段完成情况以 [分阶段路线图](docs/PHASES.md) 的验收记录为准。
