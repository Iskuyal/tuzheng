# 图证

图证帮助只有图表截图的读者检查标题与图中标注是否自洽。当前交付阶段一的单图审计路径：选团队自制样例或上传一张图片，查看观察值并确认/更正，再由程序计算增长率并展示证据与结论。

**阶段一状态：本地可验证验收已通过；真实云端模型调用尚未验证。** 当前环境没有 OpenAI API 密钥，因此样例使用明确标为“预置示例”的观察值；系统不会把预置结果说成实时 AI 输出。

## Windows 快速开始

需要 Node.js 22.12 或更高的 22.x，或 Node.js 24.x；阶段验收使用 Node 24.16、npm 11.17。

```powershell
npm install
npm run dev
```

打开 <http://127.0.0.1:5173>。根目录脚本会同时启动 Vue/Vite 页面和 Express API；API 默认使用 `127.0.0.1:3001`。

要启用新图片的 OpenAI 视觉读取，在仓库根目录复制 `.env.example` 为 `.env`，只在 `.env` 中填写 `OPENAI_API_KEY`，然后重启服务：

```powershell
Copy-Item .env.example .env
```

`OPENAI_MODEL` 可改为账户可用的视觉模型，默认候选为 `gpt-4.1-mini`。密钥只由 Node 服务端读取；不要使用 `VITE_` 前缀或把真实密钥提交到仓库。上传的新图会发送给 OpenAI 处理；预置样例不调用云端模型。

## 当前能力状态

| 能力 | 状态 | 验证证据 |
| --- | --- | --- |
| 三个自制样例、图片预览、手动框选与 PNG/JPG/WebP 上传 | 已实现并本地验证 | Edge 浏览器逐个操作样例并框选证据；上传大小上限 5 MB |
| 服务端 OpenAI Responses 视觉适配器、结构化输出和观察值校验 | 已实现；实时调用未验证 | 适配器请求契约、结构校验与无密钥错误有自动化测试；当前无 API 密钥 |
| 用户确认/更正数字，程序计算增长率 | 已实现并本地验证 | 25 条自动化行为测试；模糊样例修正后可重算 |
| 图内一致、图内矛盾、需要确认及证据/公式说明 | 已实现并本地验证 | 三例浏览器走查与自动化测试 |
| 原始数据或真实来源核验 | 未实现 | 仅凭截图不会声称核实了真实数据 |

计算使用 `(较新值 - 较早值) / 较早值 × 100`。计算值四舍五入到两位小数后，与标题中的百分比精确相等才判为“图内一致”；数值、单位、时间顺序、图中文字依据或标题主张不完整时降级为“需要确认”。

上传文件只在请求期间保存在服务端内存，不写入项目目录。模型读取失败、超时、图片格式不支持或密钥未配置时，页面显示对应说明。

## 本地验证

```powershell
npm test
npm run build
```

阶段验收细节与未验证项见 [分阶段路线图](docs/PHASES.md) 和 [阶段一验收记录](docs/STAGE-1.md)。样例图片、预置观察值与预期结果分开保存：图片在 `web/public/samples/`，观察值在 `shared/samples.ts`，预期结果在 `samples/expectations.json`。样例以 SVG 保存供页面展示；上传与视觉读取只接受 PNG、JPG、WebP，因此同内容另存了同名的 PNG 栅格渲染，可直接用来在首页试用「上传新图片 → 模型读取」这条路径。

## 产品边界

当前只检查一张截图中明确可见的标题、两个时间点、数字与单位。图内一致或矛盾不代表原始数据真实或虚假。跨图比较、坐标轴风险、来源核验、RAG、MCP、登录协作和公网部署留待后续阶段。
